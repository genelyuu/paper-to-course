## 1. 설계 결정 (모든 하위 작업이 따름)

- **기본 출력 언어: 한국어.** 사용자가 명시적으로 다른 언어를 요청할 때만 변경.
- **문체: EBS 교재 문체** (사용자 지시, 2026-11-25 — 기존 "본문 합니다체 / UI 해요체" 결정을 대체)
  - 본문 설명: **한다체 평서형** `~이다 / ~한다 / ~된다 / ~할 수 있다`. 독자를 직접 부르는 `여러분`, 의문형 수사, 감탄 표현은 최소화.
  - 학습 목표: `~을 설명할 수 있다.` `~을 비교할 수 있다.` (교과서·EBS 학습 목표 관행)
  - 문항 발문: `다음 중 ~에 대한 설명으로 옳은 것은?`, `~으로 옳지 않은 것은?`, `~을 <보기>에서 있는 대로 고른 것은?`, 지시는 `~하시오`. 선택지 앞에 `①②③④⑤`.
  - 해설·피드백: `정답` / `오답` 표지 + 한다체 해설(`~이므로 ~이다.`). 칭찬·격려 감탄문 없음.
  - UI 지시 문구: `~하시오` (예: `먼저 답을 고르시오.`).
  - 예외: 연구 대화(채팅) 요소의 등장인물 대사는 EBS 탐구 자료의 `학생 A:` 대화처럼 구어체(해요체) 허용 — 인용된 대사이기 때문.
  - 코너 이름: `학습 목표`, `개념 체크`, `탐구 자료`, `보충 설명`, `핵심 정리`, `더 알아보기`, 모듈 끝 `확인 문제`.
  - 근거: EBS 수능특강 교재 구성(개념 체크·탐구 자료·보충 설명·2점/3점 테스트)은 웹 검색으로 확인(WORKLOG #11). 한다체·발문 형식 자체를 규정한 공개 집필 지침은 검색되지 않아 EBS/검정 교과서의 관행에 따름.
- **용어 표기:** 첫 등장 시 `한글 용어(English Term)` — 반각 괄호, 괄호 앞 공백 없음. 이후 한글만. 약어(GRPO, LoRA)는 원어 유지 + 첫 등장 시 풀이. 관용 음차가 굳은 용어(트랜스포머, 어텐션)는 관용 표기 우선.
- **조사:** 영문·숫자·수식 뒤 조사는 읽는 발음 기준(`LoRA를`, `GPT가`, `$x$는`(엑스는)).
- **타이포그래피:** 한글 본문 폰트 Pretendard(jsDelivr) + 라틴 디스플레이 유지, `word-break: keep-all`, 행간 확대, 한글 이탤릭 금지.
- **UI 문자열:** `main.js`에 i18n 사전을 두고 `<html lang>` 기준으로 선택(ko 기본). 하드코딩 제거.

## 3. 완료 기준

1. 저장소 내 중국어(한자 블록) 잔존 0줄 — 의도적 예외는 lint 화이트리스트에 근거와 함께 명시.
2. 생성물 기본값이 `lang="ko"`, 한글 폰트, `keep-all` 적용.
3. `main.js` 문법 검사 통과, UI 문구 한국어.
4. 샘플 강의가 `build.sh`로 빌드되고 `lint-ko.py` 통과.
5. 모든 행동이 `docs/WORKLOG.md`에 근거와 함께 기록됨.
