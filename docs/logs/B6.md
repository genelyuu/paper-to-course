# B6 로그: README.md 한국어화, onepage_output.html 한국어화

## 변경 내역

### 행동 1: README.md 전면 한국어 재작성 (합니다체)
- 근거: 기존 README는 중국어와 영어가 반반 섞인 이중 문서였다(417행). 한국어 특화판에서는 사용자 안내가 한국어여야 하므로 중국어 섹션을 제거하고 한국어 단일 문서로 다시 썼다. 문체는 PLAN.md의 결정에 따라 합니다체로 통일했다.
- 결과: 구조는 기존과 같은 순서를 유지했다(소개, 이유, 산출물 구조, 인터랙티브 요소 18종, 5단계 파이프라인, 디자인 시스템, 교육 철학, 사용 방법, 언어, 프로젝트 구조, 크레딧, 라이선스). 코드 블록, 파일 경로, 이미지 참조(`onepage_output.png`)는 그대로 두었다.

### 행동 2: 포크 안내 추가와 업스트림 안내 유지
- 근거: 이 저장소가 원본의 포크이며 무엇이 바뀌었는지 독자가 알아야 한다. 원본 저작자 표기와 Apache 2.0 라이선스는 반드시 유지해야 한다.
- 결과: 제목을 `Paper-to-Course (한국어 특화판)`으로 바꾸고, 상단 근처에 원본 링크와 변경 사항 목록을 추가했다. 변경 목록은 한국어 기본 출력, Pretendard와 `word-break: keep-all`, UI 문구 i18n, 문체·용어 가이드, `lint-ko.py`다. 원본의 zerox-skills 이전 안내는 "업스트림 안내"로 바꿔 정보로만 남겼다. 크레딧에는 원본 저작자 ZeroxZhang과 codebase-to-course 출처를 함께 적었다.

### 행동 3: 트리거 예시를 한국어로 교체
- 근거: 지시된 한국어 트리거 5개(강의로 만들어 줘, 쉽게 설명해 줘, 인터랙티브 튜토리얼로, ./paper.pdf, arXiv URL)로 바꿔야 한다.
- 결과: 사용 방법 섹션에 해당 5개를 그대로 넣었다. 원본의 영어·중국어 트리거 목록은 삭제했다.

### 행동 4: 완성 후 검증 단계 추가
- 근거: 한국어 출력 품질을 빌드 직후 확인할 수단이 필요하다.
- 결과: 사용 방법에 `python3 references/lint-ko.py <course-dir>` 명령과 설명을 추가했다.

### 행동 5: onepage_output.html 한국어화
- 근거: 개요 인포그래픽의 보이는 중국어 문구를 모두 한국어로 바꿔야 한다(완료 기준 1번).
- 결과:
  - `<html lang="zh-CN">`을 `<html lang="ko">`로 변경했다. `<title>`도 한국어로 바꿨다.
  - 본문 폰트 스택 `--f-heading`을 `'Pretendard Variable', Pretendard, 'Noto Sans KR', sans-serif`로 바꿨다. 기존의 Noto Sans SC 웹폰트 `@import`는 제거했다. 따라서 `Noto Sans KR`은 폴백 이름일 뿐 로드하지 않으며, Pretendard가 실패하면 시스템 산세리프로 떨어진다.
  - Pretendard 스타일시트 `<link>`(cdn.jsdelivr.net, v1.3.9)를 `<head>`에 추가했다.
  - `body` 규칙에 `word-break: keep-all;`을 추가했다.
  - 글꼴 샘플 라벨은 Pretendard 기준으로 바꿨다. 레이아웃, 색상, 나머지 CSS는 바꾸지 않았다.
  - 영문 CTA 문구와 영문 예시 코드는 원문을 유지했다. 한국어 트리거 예시는 README와 맞춰 한국어로 바꿨다.
  - 원본의 "Zerox在探索"는 "Zerox가 탐구 중"으로 옮겼다. 작성자 표기는 유지했다.
- 주의: 번역 과정에서 한자 "章"이 한 번 섞였으나 검증에서 발견해 "장"으로 고쳤다.

### 행동 6: onepage_output.png는 건드리지 않음
- 근거: 지시에 따라 PNG는 수정 대상이 아니다. 이 이미지는 중국어 원본 화면을 찍은 오래된 스크린샷이므로 현재 HTML과 다르다.
- 결과: `onepage_output.png`는 변경하지 않았다. README에서는 참조 경로를 그대로 두었다. 이미지를 다시 찍어야 한다는 점은 후속 과제로 남긴다.

### 행동 7: 파일 범위 준수
- 근거: 지시는 README.md, onepage_output.html, 로그 파일만 수정하라는 것이었다.
- 결과: 위 두 파일과 `docs/logs/B6.md`만 작성 또는 수정했다.

## 알려진 후속 과제
- README가 참조하는 `references/korean-style-guide.md`, `references/glossary-ko.md`, `references/lint-ko.py`는 이 작업 시점에 아직 `references/` 디렉터리에 없다(B2, B5 작업 대상). 해당 파일이 생기기 전까지 README의 링크와 명령은 동작하지 않는다.
- `onepage_output.png`는 오래된 스크린샷이므로 한국어 HTML 기준으로 다시 캡처해야 한다.
