# B2 로그: 한국어 스타일 가이드·용어집

산출물: `references/korean-style-guide.md`, `references/glossary-ko.md`, 본 로그. 작성일 2026-11-25.
입력: `docs/PLAN.md` §1, `docs/research/korean-references.md`(이하 조사 문서), `references/lint-ko.py`, `references/interactive-elements.md`, `references/main.js`, `references/module-brief-template.md`.

### 행동 1: 입력 문서 정독
- 근거: 가이드는 PLAN §1 설계 결정을 구체화하는 문서이므로 결정·조사 근거·린터 규칙·HTML 클래스와 어긋나면 안 됨.
- 결과: 조사 문서 §6 "EBS 교재 문체"가 이미 있어 반영함(작업 종료 직전 재확인, 추가 변경 없음). 린터 규칙 ID는 KO001–KO004, KO101–KO109(종료 직전 재확인, 동일). 조사 문서 §5의 해요체 UI 예시는 PLAN §1 개정(EBS 문체)으로 폐기된 것으로 보고 따르지 않음.

### 행동 2: 우선순위 규정 (가이드 §0)
- 근거: `interactive-elements.md` 등 다른 문서에도 문체 예시가 있어 충돌 시 기준이 필요.
- 결과: 언어 문제는 이 가이드 > 다른 references의 예시, HTML 구조는 해당 문서 우선. 용어는 코스 용어표 > glossary-ko > 결정 절차.

### 행동 3: 해설 형식 `정답 ② | ~이므로 ~이다.`와 main.js 자동 표지
- 근거: `main.js` checkQuiz는 `data-explanation-*` 앞에 `<strong>정답</strong>`/`<strong>오답</strong>`을 자동으로 붙임(643·649행 부근). 현재 `interactive-elements.md` 퀴즈 예시는 속성값을 `정답.`/`오답.`으로 시작하므로 화면에 "정답 정답. …"처럼 표지가 두 번 나옴.
- 결과: 가이드 §1.4에 속성값은 `② | …`(정답), `| 정답은 ②이다. …`(오답)으로 시작하도록 규정. **조율자 조치 필요:** `interactive-elements.md` 371행대 퀴즈 예시의 속성값 수정(B2 범위 밖이라 수정하지 않음).

### 행동 4: 선택지 수와 `<보기>` 상자
- 근거: PLAN §1과 지시는 ①~⑤, `module-brief-template.md`는 ①~④ 예시, `interactive-elements.md` 예시는 3지. EBS 문항은 5지(조사 문서 §6.2, 관행).
- 결과: 확인 문제 5지 원칙, 개념 체크 2~4지 허용. `<보기>` 전용 CSS가 없어 `<div class="bogi">`를 제안으로 기재. **조율자 조치 필요:** `styles.css`에 `.bogi` 스타일 추가 여부 결정.

### 행동 5: 코너별 HTML 패턴과 콜아웃 2개 제한
- 근거: `interactive-elements.md`는 콜아웃을 모듈당 최대 2개로 제한하지만, 학습 목표(callout-info)·핵심 정리(callout-accent)를 고정 코너로 두면 보충 설명·더 알아보기를 쓸 자리가 없음.
- 결과: 제한은 선택 코너(보충 설명·더 알아보기)에만 적용하는 것으로 제안하고 "통합 단계에서 확정"이라고 명시. 탐구 자료는 결과 비교·어블레이션 토글·SVG·연구 대화·숨은 가정 찾기, 개념 체크는 1문항 퀴즈 또는 매칭.

### 행동 6: 영어 병기 대소문자
- 근거: 조사 문서 용어표는 소문자, `interactive-elements.md`·린터 메시지 예시는 Title Case(`Policy Gradient`).
- 결과: 일반 명사 소문자를 기본으로 하되 Title Case도 오류가 아니며 코스 안에서 통일하도록 규정. 글로서리의 첫 등장 예는 소문자.

### 행동 7: 조사 표 (A~Z, 0~9)
- 근거: 린터 KO104의 `LETTER_BATCHIM`(L·M·N·R)과 `DIGIT_BATCHIM`(0·1·3·6·7·8)을 그대로 따라야 가이드와 린터가 모순되지 않음. 조사 문서 §2.4의 철자 이름(L 엘, R 알, X 엑스 등)과도 일치.
- 결과: 표 2개와 예시 작성. 린터 한계 3가지를 가이드 §3.3에 명시: 단어로 읽는 약어(CLIP 클립 → `CLIP을`인데 린터는 `CLIP를` 요구), 서술격 `이다`(GPT이다), 대소문자 혼합 단어 미검사. 회피책은 명사 덧붙이기(`CLIP 모델을`).

### 행동 8: 숫자·단위·큰 수
- 근거: 조사 문서 §2.1(제43항 허용 규정, 숫자+단위 붙임 제안), KO105.
- 결과: 숫자+단위 붙임 통일, `%p`, 물결표 범위 붙임, `1억 2,000만`. 만 단위 띄어쓰기 조항은 조사 문서가 (미확인)으로 남겨 가이드에도 (미확인, 일반 지식)으로 표시. 영어 B/M/T → 억·만·조 환산표 추가.

### 행동 9: 문장 부호
- 근거: 조사 문서 §2.3(부호별 용법은 일반 지식), KO003.
- 결과: 가운뎃점은 U+00B7 `·`로 지정. 조사 문서 표의 `ㆍ`는 한글 자모 아래아(U+318D)이므로 대용 금지로 명시. 낫표는 린터가 전각 부호로 잡으므로 논문 제목은 큰따옴표. 속성값 안 인용은 곡선 따옴표(KO004 JSON 깨짐 방지).

### 행동 10: 번역투 표
- 근거: 조사 문서 §3 표 + 린터 KO101 정규식.
- 결과: 18행. 새국어생활 2012로 확인된 항목과 린터 전용 항목(`로부터`, `하는 것이 가능하다`, `~들의 ~들`)을 구분하고 공식 출처 없는 항목은 (미확인). 수학 피동(`정의된다`) 허용, `되어진다`만 금지(조사 문서 §3).

### 행동 11: 논쟁 용어 결정 (가이드 §2.4)

공통 결정 절차(가이드 §2.3): 고유 명칭 유지 → 번역어 투명성 → 다른 용어와 충돌 여부 → 쓰임 확인(G·교재) → 관용 음차.

- **likelihood → 가능도** (허용: 우도). 근거: 통계학계 "우도"와 교육·번역서 "가능도"가 갈리고 확정 표준은 확인하지 못함(조사 문서 §4.1). 학습자에게 뜻이 투명한 쪽 선택, 조사 문서 권장과 같음. 툴팁에 "우도라고도 한다" 병기. MLE도 `최대 가능도 추정`.
- **fine-tuning → 미세 조정** (허용: 파인튜닝, 세부 조정). 근거: G "세부 조정", 커뮤니티 "파인튜닝/미세 조정" 병용(조사 문서). 조사 문서 표는 권장을 "파인튜닝"으로 적고 비고에는 첫 등장 `미세 조정(fine-tuning)`을 권해 내부가 엇갈림. EBS 교재 문체는 투명한 번역어를 우선하고 `사전 학습`과 짝이 맞으므로 미세 조정 선택. 우세 표기의 정량 근거는 없음(관행).
- **ablation → 제거 실험** (허용: 어블레이션, 절제). 근거: G "절제"는 의료 용어처럼 읽힘. 논문 번역의 "제거 실험" 쓰임(조사 문서). `interactive-elements.md`의 "어블레이션 토글"은 요소 이름이므로 그대로 두되 화면 레이블은 `제거 실험`.
- **baseline → 기준 모델** (허용: 기준선, 베이스라인). 근거: G "기준"(조사 문서가 PLAN 기록을 정정). 논문 문맥에서는 비교 대상이 대개 모델이라 "기준 모델". 모델이 아니면 `기준 방법`/`기준값`.
- **convolution → 합성곱** (허용: 컨볼루션). 근거: G "컨볼루션", 수학·공학 "합성곱"(조사 문서, 일반 지식). 교재 문체와 투명성 우선.
- **regularization → 규제** (허용: 정규화). 근거: G·조사 문서 권장은 "정규화"이나 normalization(배치 정규화, G)과 같은 말이 되어 한 코스에 둘 다 나오면 혼동됨. 조사 문서도 "규제 병기" 관행을 언급. 결정 절차 3단계(충돌)에 따라 조사 문서 권장에서 벗어남.
- **gradient → 그래디언트** (허용: 기울기), 굳은 합성어는 `경사`(경사 하강법, 경사 소실, 경사 폭발, 정책 경사). 근거: 조사 문서 권장. "기울기"는 고교 수학의 직선 기울기와 겹침. G가 "경사 폭발"·"경사하강법"을 쓰므로 합성어는 경사 유지.
- **inference / reasoning → 둘 다 추론**, 한 코스에 함께 나오면 `추론 단계·추론 시` vs `추론 능력`으로 구별. 근거: G inference "추론", reasoning도 "추론"이 일반적(관행). 새 번역어를 만들지 않는 원칙.
- **label → 레이블** (허용: 라벨). 근거: G "라벨"이나 외래어 표기법상 "레이블"(조사 문서).
- **feature → 특징** (허용: 특성, 피처). 근거: G가 둘 다 씀. `특징 추출`, `특징 벡터`와 일관.
- **hallucination → 환각** (허용: 할루시네이션). 근거: G 음차, 국내 매체 "환각"(조사 문서). 투명성 우선, 조사 문서 권장과 같음.
- **training → 학습** (허용: 훈련). 근거: G "학습 세트", `학습률`·`사전 학습`과 일관.
- **expectation → 기댓값** (허용: 기대값), 같은 원칙으로 최솟값·최댓값·고윳값·특잇값·극솟값. 근거: 조사 문서가 표준국어대사전 표기로 기록(일반 지식). 사이시옷 확장 적용은 관행으로 표시.
- **return(RL) → 리턴** (허용: 누적 보상, 이득). 근거: 할인 누적 보상이라 "누적 보상"만으로는 뜻이 부족. 관행.
- **foundation model → 파운데이션 모델** (허용: 기반 모델). 근거: "기반 모델"은 base model("기본 모델")과 혼동. 결정 절차 3단계. 관행.
- **chain-of-thought → 사고의 사슬**, **in-context learning → 맥락 내 학습**. 근거: 지시에서 지정한 표기이며 검증 출처가 없어 글로서리에 "관행"으로 표시.
- **self-supervised → 자기 지도 학습** (허용: 자체 지도 학습). 근거: G는 "자체 지도 학습"이나 국내 커뮤니티 쓰임을 따름. 검증 출처 없음(관행) — G와 다른 선택임을 글로서리 비고에 명시.

### 행동 12: 용어집 확장과 출처 표기
- 근거: 지시(조사 문서 §4.2 약 80개에서 LLM 시대 용어를 더해 확장, 검증되지 않은 출처를 지어내지 않음).
