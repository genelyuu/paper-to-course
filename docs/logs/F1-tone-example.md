# F1. 교재 말투 적용 (examples/attention-ko)

### 행동
- `examples/attention-ko/modules/*.html` 3개 파일만 고쳤다. CSS/JS, `_base`/`_cover`, id·class, `data-correct`, `.sec-num`, 모듈 제목, 수치는 그대로 두었다.
- 용어 뜻풀이(`data-definition`) 22건을 사전식 명사형 종결로 바꾸었다(예: "숫자를 일렬로 나열한 것. 크기와 방향을 함께 나타냄."). `.cue dd` 7건은 이미 짧은 명사구로 통일되어 있어 고치지 않았다.
- 오답 해설(`data-explanation-wrong`) 9건 끝에 선지별 분석 한 문장을 붙였다. "옳은 것" 문항 6건에는 "①은 ~이므로 옳지 않다.", "옳지 않은 것" 문항 3건에는 "⑤는 ~이므로 옳다." 꼴을 썼다. `data-explanation-right`는 그대로 두었다.
- 모듈마다 핵심 정리 목록 끝에 풀이 전략 한 줄(~하라.)을 넣었다.
  - 모듈 0: 비중을 비교하는 문항은 쿼리와 각 키의 내적부터 계산하라.
  - 모듈 1: 나누는 값을 묻는 문항은 분산이 아니라 그 제곱근인지 확인하라.
  - 모듈 2: 수치 비교 문항은 같은 데이터와 조건에서 잰 값인지부터 확인하라.
- 모듈마다 첫 화면 첫 문단 앞에 도입 질문 한 문장(한다체 의문형)을 넣었다.
  - 모듈 0: 순환 신경망 없이 어텐션만으로 번역 모델을 만들 수 있을까?
  - 모듈 1: 각 위치는 다른 위치의 정보를 어떻게 가져올까?
  - 모듈 2: 어텐션만 쓴 모델은 기존 번역 모델보다 정말 나을까?

### 근거
- 지학사 『자신 있어, 어휘』 1·2단계, 『중등 수능 독해』 Level 2(192쪽)에서 뽑은 통계: 개념 설명은 한다체 평서(379건), 뜻풀이는 명사형 종결(34건), 문항 지시문은 "~하시오"(120건), 오답 해설은 선지 번호별 "~이므로 ~않다." 꼴, 풀이 전략은 짧은 명령형 "~하라"(54건), 도입은 질문으로 시작한다.
- 원번호 뒤 조사는 읽는 소리(일·이·삼·사·오)에 맞추어 ①은, ②는, ③은, ④는, ⑤는으로 썼다.
- 덧붙인 해설 문장은 모두 본문·표에 있는 사실과 수치(내적 2와 1, 분산 64, 41.8 > 40.46, 25.4 < 25.8 등)만 썼다.
