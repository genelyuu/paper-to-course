# A1 작업 로그 (한국어 특화 참고자료 조사)

작성일: 2026-11-25. 산출물은 `docs/research/korean-references.md`입니다.

### PLAN.md 및 Pretendard CSS 확인 (curl)
- 근거: 설계 결정(§1)과 Pretendard 정확한 URL, 버전 태그 존재 여부를 검증해야 했음.
- 결과: PLAN.md 확인. `.../pretendard@v1.3.9/dist/web/variable/pretendardvariable-dynamic-subset.min.css`가 HTTP 200. 내부 woff2 경로(`packages/pretendard/dist/web/variable/woff2-dynamic-subset/...`)도 200. jsDelivr 패키지 목록과 GitHub API 최신 릴리스 모두 v1.3.9(2023-11-05). SRI 금지 주석 확인.

### WebSearch: W3C klreq / keep-all / line-height
- 근거: 한글 조판 요구사항 공식 출처 필요.
- 결과: klreq 문서(w3.org/TR/klreq) 위치 확인. 검색 요약만으로는 keep-all, line-height 내용이 없어 문서를 직접 열기로 함.

### WebFetch: https://www.w3.org/TR/klreq
- 근거: 줄바꿈, 행간, 이탤릭, 자간의 절 번호 확인.
- 결과: 7.1.1 줄바꿈, 7.1.4 단어 분리 금지, 7.4.1 행간(비례 160% 예시), 7.3.1 자간 기본 0 확인. 4.3 이탤릭, 6.3 강조 절은 내용이 비어 있음. keep-all이라는 이름은 문서에 없음.

### WebFetch: MDN word-break
- 근거: keep-all의 CJK 동작과 overflow-wrap과의 관계.
- 결과: keep-all은 CJK 단어 중간 줄바꿈 금지. break-word는 deprecated이며 `overflow-wrap: anywhere`와 동치.

### WebFetch: GitHub orioncactus/pretendard
- 근거: 라이선스와 권장 font-family 스택.
- 결과: SIL OFL, 권장 스택 확보. 이후 raw LICENSE로 OFL 1.1과 저작권자(Kil Hyung-jin, Adobe) 확인.

### Bash: Google Fonts CSS2 엔드포인트 4종 요청
- 근거: Noto Sans KR, Noto Serif KR, Nanum Gothic Coding, Nanum Myeongjo 사용 가능 여부.
- 결과: 모두 HTTP 200. Nanum Gothic Coding은 font-face 반환 확인. D2Coding jsDelivr 경로(`projectnoonnu/...`)는 404라 (미확인) 처리.

### WebFetch: fonts.google.com Noto Sans KR specimen
- 근거: Noto 라이선스와 가중치 확인.
- 결과: 제목만 반환되어 실패. Noto의 OFL 여부는 (일반 지식)으로 표기.

### WebSearch + WebFetch: 한글 맞춤법 띄어쓰기(제43항) 및 국립국어원 "띄어쓰기의 이해"
- 근거: 단위 명사, 숫자+단위 규칙의 공식 근거.
- 결과: 단위 명사는 띄어 쓰는 것이 원칙, 아라비아 숫자 뒤에서는 붙여 쓰기 허용(관용은 붙임), 한글 수사는 띄어쓰기. "만 단위" 규정은 확인하지 못함.

### WebFetch: korean.go.kr 한글 맞춤법 본문 (kornorms)
- 근거: 문장 부호 규정 조문 확인.
- 결과: 본문만 반환되어 부록(문장 부호) 조문은 확인 불가. 2014-39호 개정 개요는 검색 결과로 보강했고 부호별 용법은 (일반 지식)으로 표기.

### WebSearch: 문장 부호 해설 / 2014 개정
- 근거: 개정 시기와 줄임표 허용 범위.
- 결과: 고시 제2014-39호, 2015-01-01 시행, 24종 94개 조항, 줄임표 허용 확대. 『문장 부호 해설』 게시물 위치 확인.

### WebSearch: 외래어 표기법 기본 원칙
- 근거: 외래어 표기법 5개 원칙의 정확한 내용.
- 결과: 제1~5항(24자모, 1음운 1기호, 받침 7자, 된소리 불사용, 관용 존중) 정리. 위키문헌과 국립국어원 해설 링크 확보. 위키문헌 OCR이 불완전하여 원문 대조 권장으로 표기.

### WebSearch (2회): 영문 약어·알파벳·숫자 뒤 조사
- 근거: 국립국어원의 조사 선택 공식 문구를 찾기 위함.
- 결과: 공식 문구는 찾지 못함. 약어 읽기 방식(acronym/initial)과 사전 처리에 관한 기사만 확보. 읽는 소리 기준 규칙은 일반 원리로 정리하고 (미확인) 표기.

### WebSearch: 번역투 패턴 (3회)
- 근거: 번역투의 공식 근거와 교정 예시.
- 결과: 국립국어원 『새국어생활』 2012 봄호 특집, 2022년 7월 소식지, 위키독스·한경·kormedi 2차 자료 확보.

### WebFetch + markitdown: 새국어생활 2012 PDF, 소식지 2022_7 PDF
- 근거: 번역투 원문 근거 확보.
- 결과: WebFetch는 PDF 바이너리라 본문 추출 불가였으나 저장된 PDF를 markitdown으로 변환. 새국어생활 2012에서 '가지다 / 에 있어서 / 에 의하여 피동 / 복수 들 / 만들다·대하다' 근거 문장과 대안 번역 예시 확인. 2022 소식지는 코너 제목만 보이고 본문은 추출되지 않아 (미확인).

### WebFetch: wikidocs 165243 / 165163
- 근거: 이중피동 등 2차 정리 확인.
- 결과: 165243은 403, 165163은 403(두 번째는 검색 요약만 사용). 이중피동과 되다→하다 사례는 검색 요약으로 대체해 2차 자료로 표기.

### WebSearch (3회): 한국정보과학회·TTA·대한수학회·통계학회 용어
- 근거: 공식 용어집에서 표준 번역어 확인.
- 결과: 공식 용어집 본문은 찾지 못함. Google ML 용어집 한국어판, d2l-ko, itwiki·koreascience에서 likelihood 우도/가능도 분열 확인.

### WebFetch + curl + python: Google 머신러닝 용어집(ko)
- 근거: 검증 가능한 ML 번역어 출처 확보.
- 결과: WebFetch 요약은 추측이 섞여 있어 신뢰하지 않고, HTML을 직접 내려받아 헤딩 764개에서 용어를 추출. 확인한 번역: 경사하강법(붙임), 과적합, 손실 함수, 절제(ablation), 기준(baseline), 세부 조정(fine-tuning), 사전 학습, 학습 세트, 라벨, 컨볼루션, 할루시네이션, 리워드, 정책, 대규모 언어 모델 등. 온도, 기댓값, 분산, 사후 확률은 항목 없음. WebFetch 요약표의 일부 값(예: 기준 모델, 제거 실험, 합성곱)은 실제 용어집과 달라 채택하지 않음.

### WebSearch: 한글 이탤릭 / 행간 / 자간
- 근거: 권장 line-height와 letter-spacing, 가짜 이탤릭 근거.
- 결과: 본문 행간 1.5~1.8(1.6 선호) 2차 자료 확보. 가짜 이탤릭 근거는 공식 자료가 없어 (일반 지식) 표기. klreq 4.3 절이 비어 있다는 사실로 보강.

### WebSearch + WebFetch: 토스 UX 라이팅
- 근거: UX 라이팅 원칙 근거.
- 결과: 토스피드 UX writer 인터뷰에서 잡초 뽑기, 효용 우선, 공감, 컴포넌트별 문구 규칙, Zero Jargon 확인. 해요체를 규칙으로 명시한 부분은 없었음. 해요체 통일 서술은 2차 자료에 의존하므로 비고에 기재.

### WebSearch: 교과용도서 편찬상의 유의점 / 종결어미 / 학습 목표 "~할 수 있다"
- 근거: EBS 문체(한다체, 학습 목표 서술) 규정의 공식 출처 확인.
- 결과: 2023-01 편찬준거 공고 사실만 확인. 문체 조항과 "~할 수 있다" 규정은 찾지 못해 (미확인, 관행) 처리. 1999 국립국어연구원 자료와 학습목표 진술 연구 링크를 확보했으나 본문은 열람하지 못함.

### WebSearch: EBS 수능특강 구성 (개념 체크, 탐구 자료, 3점 테스트, 정답과 해설)
