# D1 작업 로그 (C1 지침 모순 정리)

작성일: 2026-11-25. 근거는 `docs/logs/C1.md`의 모순·모호함 목록과 `docs/PLAN.md` §1입니다. 수정 범위는 SKILL.md와 references의 지정된 md 파일입니다. `main.js`, `styles.css`, `lint-ko.py`, `examples/`는 수정하지 않았습니다.

### 행동: 표지 제목 괄호 공백 수정(결정 1)
- 근거: C1 #14, KO103. `interactive-elements.md`의 표지 예시 `방법 (Nonsense Helps)`가 괄호 앞 공백 금지와 충돌했습니다.
- 결과: 공백을 제거하고 표지 규칙에 `한국어 제목(English Original Title)` 형식을 명시했습니다. SKILL.md Step 2.5에도 같은 형식을 적었습니다.

### 행동: 약어 첫 등장 형식 통일(결정 2)
- 근거: C1 #12. SKILL.md는 약어 먼저, 스타일 가이드는 한글 먼저였습니다.
- 결과: 모든 문서에서 `한글 풀이(English Full Name, ACRONYM)`를 기본으로 하고, 약어가 굳은 경우(GRPO, BLEU, GPU)의 `ACRONYM(English Full Name, 한글 풀이)`를 예외로 두었습니다. 예외 문구는 스타일 가이드 §2.2에 한 번 정의하고 SKILL.md와 interactive-elements 요약에 같은 취지로 적었습니다.

### 행동: 영어 병기 Title Case 통일(결정 3)
- 근거: C1 #13. 스타일 가이드와 용어집은 소문자, SKILL.md와 interactive-elements는 대문자였습니다.
- 결과: 스타일 가이드 §2.1, §2.2, §2.4, §2.3의 예와 ✗/✓ 표를 Title Case로 고쳤습니다. `glossary-ko.md`의 "첫 등장 표기 예" 열은 스크립트로 일괄 변환했습니다(235행). 약어·고유 명칭은 그대로 두었고 `i.i.d.`, `p-value`는 소문자 표기를 유지했습니다. 용어집 사용법 문구도 Title Case 규칙으로 바꿨습니다.

### 행동: 숫자와 단위 규칙 통일(결정 4)
- 근거: C1 #15. 스타일 가이드는 `16GB`를 붙이고 gotchas는 `3 kg`을 띄웠습니다.
- 결과: 한글 단위 명사와 `%`, `%p`, `°`는 붙이고 라틴 SI·컴퓨팅 단위 기호는 한 칸 띄우는 규칙으로 스타일 가이드 §4, gotchas, SKILL.md, interactive-elements 요약을 맞췄습니다. 모델 규모 `7B`는 규모 약호이므로 붙인다고 적었습니다(이 부분은 결정에 없던 보충입니다).

### 행동: 퀴즈 해설 형식 통일(결정 5)
- 근거: C1 #16, #10, #11. content-philosophy의 `정답이다.`/`오답이다.` 예가 main.js의 자동 표지와 중복되었습니다.
- 결과: content-philosophy 해설 문체를 `data-explanation-right="② | …"` / `data-explanation-wrong="| 정답은 ②이다. …"` 형식으로 바꿨습니다. interactive-elements 퀴즈 절에 해설 속성 위치(`.quiz-question-block`), 표지 자동 부착(KO110), 해설 안 `$…$` 수식 지원(결정 15b)을 규칙으로 추가했습니다.

### 행동: SVG 한글 라벨 줄바꿈 규칙 통일(결정 6)과 이탤릭 제거(결정 7)
- 근거: C1 #17, #18. gotchas는 `<text>` 수동 분할 금지, design-system은 `<tspan>` 허용이었고 계보 SVG 예시는 `font-style="italic"`을 썼습니다.
- 결과: 한 줄은 `<text>`, 두 줄은 어절 경계의 `<tspan x dy="1.3em">`, 세 줄 이상과 문단은 `<foreignObject>`와 `keep-all`로 gotchas, design-system, interactive-elements, SKILL.md에 같은 규칙을 적었습니다. 예시의 italic은 `font-weight="500"`으로 바꾸고 SVG 이탤릭 금지를 명시했습니다. gotchas의 `overflow-wrap` 서술은 `styles.css`가 `break-word`이므로 "CSS를 따른다"로 단순화했습니다(C1 #19).

### 행동: 배경 지식 표시 정의(결정 8)
- 근거: C1 #4. `styles.css`에서 `eyebrow`, `screen-label`, 배지류를 검색했으나 모듈 화면용 소형 라벨 클래스는 없었습니다(`course-cover-abstract-label`, `translation-label` 등은 용도가 다름).
- 결과: `callout callout-info` + 제목 `배경 지식`을 표준 표시로 정하고 마크업을 interactive-elements 모듈 골격 절에 적었습니다. 이 콜아웃은 선택 코너 상한에 넣지 않습니다. SKILL.md와 content-philosophy가 이 절을 가리킵니다.
