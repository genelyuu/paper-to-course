# A2 로그: references/main.js UI 문구 i18n 전환

## 변경 내역

### 행동 1: `I18N` 사전과 `i18n()` 헬퍼 추가
- 근거: 하드코딩된 중국어 UI 문구를 언어별 사전으로 분리하면, 상위(upstream) 원본 동작(`lang="zh*"`)을 그대로 보존하면서 `<html lang>` 값만으로 UI 언어를 바꿀 수 있다. 헬퍼 이름은 지시대로 `t`를 쓰지 않았다. 원본 396행 근처 `forEach` 콜백 안의 `const t = ...`(드래그앤드롭 타깃 요소)와 이름이 충돌하기 때문이다. 해당 콜백 안에서 `t(...)`를 호출해야 할 때 섀도잉되는 문제를 피하려고 `i18n`으로 정했다.
- 결과: IIFE 내부, `$`/`$$` 헬퍼 바로 아래(약 30~70행)에 `I18N` 객체(`ko`, `zh`, `en`)와 `i18n(key, ...args)` 함수를 추가했다. `zh` 블록에는 `// zh: upstream 원본 문구 보존 (lang="zh*" 일 때만 사용)` 주석을 달았고, 값은 원본 중국어 문구와 글자 단위로 동일하다. 언어 코드는 `toLowerCase().slice(0, 2)`로 판별하고, 사전에 없는 언어나 키는 `ko`로 떨어진다.

### 행동 2: 문구 교체 (원본 기준 12개 행, 15개 문자열 위치)
- 근거: 단순 치환 대신 헬퍼 호출로 바꿔야 언어별 분기가 한 곳에서 관리된다. 가능한 곳은 HTML 조각 구조(`'<strong>' + ... + '</strong> '`)를 그대로 유지했다.
- 결과 (원본 행 번호 기준):
  - 277, 593: `'请先选择一个答案！'` → `i18n('selectFirst')`
  - 285, 601: `'<strong>正确！</strong> '` → `'<strong>' + i18n('correct') + '</strong> '`
  - 291, 607: `'<strong>不太对。</strong> '` → `'<strong>' + i18n('incorrect') + '</strong> '`
  - 396: `'拖放到这里'` → `i18n('dropHere')`
  - 485: `'步骤 ' + step + ' / ' + stepsData.length` → `i18n('step', step, stepsData.length)`
  - 528: `'点击"下一步"开始'` → `i18n('clickNextToStart')`
  - 561: `'<strong>找到了！</strong> '` → `'<strong>' + i18n('found') + '</strong> '`
  - 568: `'不是这一行，继续找...'` → `i18n('notThisLine')`
  - 634: `'步骤 ' + (current + 1) + ' / ' + steps.length` → `i18n('step', current + 1, steps.length)`
- 주의: 중간에 `replace_all`이 새로 만든 `zh` 사전 값(`selectFirst`)까지 `i18n('selectFirst')`로 바꿔 버렸다. 재귀 호출이 되는 버그였으므로 즉시 원래 중국어 문자열로 되돌렸고, 최종 파일에서 `zh` 블록 값이 원문과 같은지 확인했다.

### 행동 3: 그 밖의 동작 변경 없음
- 근거: 지시에 따라 문구 치환 외에는 건드리지 않았다.
- 결과: 로직, 셀렉터, 이벤트 처리, 데이터 속성 이름은 변경하지 않았다. 수정한 파일은 `references/main.js` 하나다.

### 행동 4: 로그 파일 작성
- 근거: 작업 결과를 추적할 수 있도록 로그를 남기라는 요청이 있었다.
- 결과: `docs/logs/A2.md`(이 파일)를 새로 만들었다. `docs/logs/` 디렉터리는 원래 없었다.
