# A3 로그 — 한글 타이포그래피 (`_base.html`, `styles.css`, `design-system.md`)

대상: `references/_base.html`, `references/styles.css`, `references/design-system.md`. 색상은 건드리지 않았다.

### `<html lang>`을 `ko`로 변경
- 근거: `lang`은 스크린리더 발음, 폰트 선택, `:lang(ko)` 셀렉터의 전제 조건이다. 기존 `zh-CN`은 한자 글리프 우선 선택과 잘못된 음성 합성을 유발한다.
- 결과: `<html lang="ko">`. 이후 모든 한글 전용 CSS가 `:lang(ko)`로 동작한다.

### Pretendard Variable 추가 (jsDelivr, 버전 고정)
- 근거: Pretendard 저장소(https://github.com/orioncactus/pretendard)가 권장하는 dynamic-subset 가변 폰트 CSS이다. 필요한 글리프만 분할 로드해 전체 한글 폰트(수 MB)를 받지 않는다. 버전을 `v1.3.9`로 고정해 CDN 변경에 따른 렌더링 변화를 막았다. `curl -sI`로 확인: `HTTP/2 200`.
- 결과: `_base.html`에 `<link>` 추가, `preconnect cdn.jsdelivr.net` 추가. DM Sans는 Pretendard가 라틴을 충분히 커버하므로 제거했고, Google Fonts 요청은 Bricolage Grotesque와 JetBrains Mono만 남겼다(요청 크기 감소).
- 한글 고정폭 폰트(Nanum Gothic Coding)는 웹폰트로 추가하지 않았다. 추가 네트워크 비용 대비 이득이 작고, 코드 속 한글은 주로 주석이므로 시스템/D2Coding 및 Pretendard 폴백으로 충분하다고 판단했다.

### `_base.html` 문자열과 주석 한국어화
- 근거: PLAN §1 UI 문자열 한국어 원칙. 접근성 라벨은 스크린리더가 읽으므로 반드시 번역해야 한다.
- 결과: `aria-label` "강의 목차", "목차 열기/닫기". 커스터마이즈 주석과 폰트 주석을 한국어로 번역. 플레이스홀더(`COURSE_TITLE`, `ACCENT_*`, `NAV_DOTS`, `SIDEBAR_ITEMS`)는 그대로.

### 폰트 토큰 (`--font-display`, `--font-body`, `--font-mono`)
- 근거: CSS는 글리프 단위로 폰트를 폴백하므로 라틴 폰트를 앞에, 한글 폰트를 뒤에 두면 영문은 Bricolage, 한글은 Pretendard로 렌더링된다. 본문은 Pretendard 하나로 통일해 한영 혼용 시 굵기·x-height 불일치를 줄였다. 시스템 폴백으로 Apple SD Gothic Neo, Malgun Gothic, Noto Sans KR을 둬 CDN 실패 시에도 한글이 깨지지 않는다.
- 결과: display는 Bricolage → Pretendard 폴백, mono는 JetBrains Mono → D2Coding → Nanum Gothic Coding → Pretendard.

### 행간 토큰 `--leading-*`
- 근거: W3C klreq(https://www.w3.org/TR/klreq/)는 한중일 문자가 em 박스를 꽉 채우므로 라틴보다 넓은 행간을 권한다. 기존 제목 1.15는 한글 제목에서 윗줄 받침과 아랫줄 초성이 붙는다.
- 결과: tight 1.15 → 1.35, snug 1.3 → 1.45, normal 1.6 → 1.75, loose 1.8 → 1.9. `.module-title` 등 토큰을 쓰는 모든 셀렉터에 자동 반영된다.

### 줄바꿈: `word-break: keep-all; overflow-wrap: break-word`
- 근거: 한글은 기본 `word-break: normal`에서 글자 사이 어디서나 줄이 바뀌어 어절이 쪼개진다. `keep-all`은 공백에서만 끊는다(MDN word-break). `overflow-wrap: anywhere`는 긴 토큰을 끊어 주지만 min-content 크기도 줄여 flex/grid 자식이 과도하게 수축할 수 있어, min-content에 영향이 없는 `break-word`를 택했다. 긴 URL·영문 토큰은 `break-word`로도 넘침 없이 줄바꿈된다. `line-break: strict`로 금칙 처리(klreq)도 강화했다.
- 결과: `body`와 `html:lang(ko)`에 적용. 툴팁(`.term-tooltip`, `.nav-dot::after`)에도 `keep-all`과 `max-width: 320px` 적용.

### 코드(`pre`, `code`) 줄바꿈 분리
- 근거: 기존 `word-break: break-word`(비표준 별칭)는 본문 keep-all과 충돌할 수 있다. 코드는 긴 식별자를 끊어야 하므로 별도 규칙이 필요하다.
- 결과: `word-break: normal; overflow-wrap: anywhere`(기존 `white-space: pre-wrap` 유지). 코드는 인라인 크기가 min-content에 영향을 주지 않는 맥락이라 `anywhere`를 허용했다.

### 대문자 라벨 자간 토큰화 (`--tracking-label*`)
- 근거: `text-transform: uppercase; letter-spacing: 0.1em`은 라틴 소문자 라벨용 디자인이다. 한글은 대문자 개념이 없고, 넓은 자간은 음절을 흩어 보이게 한다. 기존 4곳(0.1em ×3, 0.12em, 0.05em)을 일일이 고치면 규칙이 분산되므로 변수로 치환했다.
- 결과: 기본값은 기존과 동일(0.1/0.12/0.05em), `:lang(ko)`에서 0.02/0.03/0.01em으로 덮어쓴다. 영어 강의로 `lang="en"`을 쓰면 원래 모양이 유지된다.

### 한글 제목·본문 자간
- 근거: Pretendard는 한글 제목에서 -0.01~-0.02em 정도가 일반적으로 쓰이며 큰 글자에서 더 균형 있다.
- 결과: `:lang(ko)` 제목류(`h1~h4`, `.module-title`, `.screen-heading`, `.screen-header h3`)에 `-0.02em`, `.module-subtitle` `-0.01em`, 본문 `-0.005em`.

### 이탤릭 제거 (`.lineage-edge-label`, `em`, `i`)
- 근거: 한글에는 이탤릭 글리프가 없어 브라우저가 가짜 기울임을 만들고 획이 일그러진다. 한국어 인쇄물은 이탤릭 대신 굵게·드러냄표를 쓴다.
- 결과: `:lang(ko)`에서 `.lineage-edge-label`은 `font-style: normal; font-weight: 500`, `em/i`는 normal + 600 + 강조색. KaTeX 내부 `em/i`는 이탤릭 유지. `body`에 `font-synthesis: none`을 넣어 가짜 굵기/기울임을 막았다. `.ko-emphasis` 드러냄표 유틸리티(`text-emphasis: dot; text-emphasis-position: over right`)를 선택 사항으로 추가.

### KaTeX 충돌 방지
- 근거: 상속된 `keep-all`·음수 자간이 수식 조판에 새어 들어가면 안 된다. 한글 문장 속 인라인 수식은 앞뒤 글자와 붙어 보인다.
- 결과: `.katex { word-break: normal; overflow-wrap: normal; letter-spacing: normal }`, 문단·목록·표 안 `.katex`에 좌우 `0.12em` 여백, `.katex-display` 상하 여백.

### `styles.css`에 `KOREAN TYPOGRAPHY` 섹션 신설
- 근거: 한글 전용 규칙을 한곳에 모아 두면 후속 수정과 검토가 쉽고, 파일 끝에 두면 기존 규칙을 덮어쓴다.
- 결과: 파일 끝에 `/* ── KOREAN TYPOGRAPHY ── */` 섹션. 중괄호 균형 검사 통과(357 / 357). 색상은 변경 없음.

### `design-system.md` 한국어 재작성
- 근거: PLAN §1 기본 출력 언어. 하위 에이전트가 이 문서를 참조하므로 새 토큰과 규칙이 정확히 반영돼야 한다.
- 결과: 전체 한국어화(코드 블록 유효 유지), "디자인 아이덴티티"(폰트 갱신) 및 "한글 타이포그래피" 섹션 신설, 타이포그래피 토큰 갱신, SVG 예시 "This Paper" → "이 논문", SVG 한글 주의사항(글자당 약 1em 폭, CSS로 폰트 지정, 여러 줄은 `<foreignObject>`) 추가.
