# B4 작업 로그: references/interactive-elements.md 한국어화

### 행동: 설계 결정 확인 및 전체 재작성 범위 정의
- 근거: `docs/PLAN.md` §1 (합니다체 본문, 해요체 UI·퀴즈·대화, `한글 용어(English Term)`, 반각 괄호, 발음 기준 조사)
- 결과: 설명 문장(머리말, 규칙, 연결 방식 설명)과 HTML 예시 속 텍스트를 모두 한국어로 옮김. 목차 18개 링크가 새 제목 앵커와 모두 일치함(스크립트로 확인).

### 행동: 클래스명·data-* 속성명·id·HTML 구조는 일절 수정하지 않음
- 근거: `main.js`와 `styles.css`가 이들에 의존함. 바꾸면 인터랙션이 깨짐.
- 결과: 텍스트 노드와 사람이 읽는 속성 값(`data-definition`, `data-explanation-right/wrong`, `data-detail`)만 번역. 파일 안에 `data-steps` 속성은 없음(0건).

### 행동: Abstract를 "초록"으로 번역
- 근거: 국내 학술 논문에서 abstract의 표준 대응어는 "초록"이며, 요구 사항에도 명시됨. "요약"은 summary와 구분되지 않음.
- 결과: 표지 라벨 `초록`, 배지 `인터랙티브 튜토리얼`, 메타 `모듈 7개`/`약 45분`/`중급`, CTA `학습 시작하기 →`.

### 행동: 의사코드의 INPUT/OUTPUT/FOR EACH/IF…THEN 키워드는 영어 유지, 주석(`//`)과 설명 패널만 한국어
- 근거: 의사코드 키워드는 언어 중립적 관례이고, 규칙 문구에도 "특정 언어에 얽매이지 않는다"고 적혀 있음. 번역하면 오히려 비표준이 됨.
- 결과: `INPUT: 프롬프트 q, ... // 입력` 형태. 오른쪽 설명은 합니다체, 규칙에 명시.

### 행동: 문체 구분 적용
- 근거: PLAN §1. 본문·수식 설명·논문 인용 카드·용어 정의는 합니다체, 퀴즈 피드백·보기·대화·드래그앤드롭·어블레이션 설명·콜아웃은 해요체.
- 결과: 한 요소 안에서 문체가 섞이지 않음. 버튼은 명사형/해요체("이전 단계", "다음 단계", "처음부터", "정답 확인", "다시 풀기").

### 행동: 용어·조사 처리
- 근거: PLAN §1 (반각 괄호, 괄호 앞 공백 없음, 발음 기준 조사)
- 결과: `그룹 상대 정책 최적화(Group Relative Policy Optimization, GRPO)`, `GRPO는`, `GRPO를`, `LoPE는`. Policy Gradient 예시 문장은 요청한 형식 `정책 경사(Policy Gradient): ...`를 규칙 항목에 수록. 용어 태그 뒤 조사는 줄바꿈 공백이 끼지 않게 `</span>를`처럼 붙임.

### 행동: 퍼센트 차이를 `%p`로 교정
- 근거: 원문 `+6.2% vs 基线`은 78.3%-72.1%이므로 백분율 차이(퍼센트포인트)임. 한국어에서는 `%p`로 구분해야 정확함.
- 결과: `기준선 대비 +6.2%p`, `+2.7%p`.

### 행동: SVG 한글 라벨 주의사항 추가
- 근거: 한글은 글자당 약 1em 너비라 영문 기준 박스에서 넘침. 한글 어절 중간 줄바꿈 방지 필요.
- 결과: SVG 규칙에 박스 너비 계산법, 8자 초과 시 2줄 분리 또는 `<foreignObject>`(+ `word-break: keep-all`) 사용 안내와 예시 스니펫 추가. 기존 SVG 라벨은 한국어화(박스 크기 160 유지, 9자 이내).

### 행동: 상단에 "한국어 콘텐츠 작성 원칙 (요약)" 섹션 추가
- 근거: 하위 에이전트가 예시와 함께 규칙을 바로 볼 수 있어야 함.
- 결과: 8개 항목(문체, 용어 첫 등장, 반각 괄호, 조사, 숫자·단위/`%p`, 인용, 수식 띄어쓰기, 스타일 가이드 포인터 `references/korean-style-guide.md`). 가이드 파일은 다른 에이전트가 작성 중이므로 링크만 연결.

### 행동: 제목 앵커 방식
- 근거: GitHub식 앵커(소문자, 공백→`-`, 구두점 제거, 한글 유지). 슬래시와 가운뎃점은 앵커가 이중 하이픈이 되므로 "와"/"및"으로 바꿈.
- 결과: `## 표지와 히어로 섹션 (Cover Page)` → `#표지와-히어로-섹션-cover-page` 등. 스크립트로 18개 목차 링크 전부 대응 확인.

## 2차 수정: EBS 교재 문체

### 행동: 예시 전체를 한다체 평서형으로 전환
- 근거: 갱신된 `docs/PLAN.md` §1 "문체: EBS 교재 문체"가 합니다체/해요체 결정을 대체함.
- 결과: 표지 초록·부제, 수식 설명, 의사코드 설명, 인용 카드, 기여·단계 카드, 용어 툴팁 `data-definition`, 콜아웃, 어블레이션 설명, 드래그앤드롭 라벨을 `~이다/~한다`로 바꿈. `여러분`과 감탄 표현 없음. 표지 CTA는 `학습 시작하기 →` 유지.

### 행동: 퀴즈·가정 찾기를 EBS 발문·선택지·해설 형식으로 변경
- 근거: PLAN §1 문항 발문 규정(`~에 대한 설명으로 옳은 것은?`, `~하시오`, `①②③`, `정답/오답` + 한다체 해설, 칭찬 없음).
- 결과: 선택지 가시 텍스트 앞에만 ①②③을 붙임(`data-value`, `data-correct`는 불변). 선택지가 3개라 ④는 추가하지 않음(구조 불변 제약). 해설은 `정답. ~이므로 ~이다.` / `오답. ~`. 지시문 `~고르시오`, 드롭 영역 `여기에 놓으시오`.

### 행동: 코너 이름과 학습 목표 패턴 추가
- 근거: PLAN §1 코너 이름 목록.
- 결과: 요약 섹션에 `학습 목표/개념 체크/탐구 자료/보충 설명/핵심 정리/더 알아보기/확인 문제` 사용 시점 불릿과 `~을 설명할 수 있다` 학습 목표 패턴 불릿 추가. 콜아웃 예시 제목 `핵심 통찰`을 `핵심 정리`로 바꾸고 변형(accent/info/warning)별 제목 대응을 규칙에 명시.

### 행동: 연구 대화 화자를 `학생 A` / `교사`로 변경, 대사는 해요체 유지
- 근거: PLAN §1 예외(EBS 탐구 자료의 `학생 A:` 대화처럼 구어체 허용). `data-sender` 값 등은 불변, 아바타 글자만 `학`/`교`.
- 결과: 대사 해요체 유지.

### 행동: 메타 설명(작성자용 규칙·연결 방식 문장)은 합니다체 유지
- 근거: PLAN의 문체 규정은 학습자용 출력물 대상이며, 이 문서의 작성자용 안내는 출력물이 아님. 단 "작성 원칙 (요약)" 섹션은 요청에 따라 한다체로 통일.
- 결과: 제목 변경 없음이라 목차 앵커 재검사 결과 불일치 0건. 중국어·전각 문자 잔존 0건(grep 출력 없음).
