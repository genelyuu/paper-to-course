# 모듈 브리프 템플릿

> **읽는 시점:** 병렬 경로로 복잡한 논문을 다루는 3.5단계. 모듈마다 브리프를 하나씩 채워 `course-name/briefs/0N-slug.md`로 저장한다.
> 브리프 본문은 한국어로 쓴다. 학습 목표와 코스 문구 예시는 EBS 교재 문체(한다체)로 쓴다. 상세 기준은 `references/korean-style-guide.md`, 용어는 `references/glossary-ko.md`를 따른다.

---

## 모듈 N: [제목]

- **논문 절 번호·제목:** [`.module-number`에 쓸 연속 번호(`1`, `2`, `3` …, 논문 절 번호를 쓰지 않는다)와 `.module-title`에 쓸 논문 절 제목의 한국어 번역(예: `어텐션`, `결과`). 교재식 제목을 새로 짓지 않는다. 제목은 논문 절 제목의 한국어 번역이고 번호는 1부터 연속 정수이다. id·파일명(`module-0`, `00-`)만 0부터 시작한다(모듈 0 = id 기준 첫 모듈, 화면 번호 1).]

### 학습 목표
2~3개를 `~할 수 있다.` 형식으로 쓴다. 행위 동사(설명하다, 비교하다, 구하다, 판단하다)를 쓰고 "이해한다", "안다"는 피한다.
- [예: 손실 함수의 값이 커지는 조건을 설명할 수 있다.]
- [예: 두 방법의 훈련 곡선을 비교할 수 있다.]

### 서사 구조
- **직관:** [형식 표현에 앞서 핵심 아이디어를 담은 일상어 한 문장]
- **도입 질문:** [첫 페이지에 한다체 발문을 최대 1개 둔다. 학습자가 이 모듈에 관심을 갖게 하는 질문이나 상황]
- **핵심 통찰:** [학습자가 반드시 가져가야 할 한 가지]
- **논문과의 연결:** [이 모듈이 논문의 서사에서 맡는 역할]

### 맡은 논문 그림·표
`briefs/figures.md`에서 이 모듈에 배정된 그림·표를 모두 적는다. 하나도 빠뜨리지 않는다.
- [그림 n | 그림이 말하는 것 | 대신 쓸 새 예시(한국어) | 재현 방식(전용 쪽 SVG·차트·표·따라가기) | 놓을 쪽 제목]
- 결과 그래프는 새 예시 대신 원문 수치를 그대로 쓰고, 읽는 법만 다른 예시로 푼다.

### EBS 코너 배치
모듈의 흐름은 `학습 목표 → 개념 설명 → 개념 체크 → 탐구 자료 → 핵심 정리 → 확인 문제`이다. 각 코너에 들어갈 내용을 정한다.
- **개념 체크:** [개념 설명 직후의 짧은 점검 문항 또는 빈칸. 예: `학습 목표 1`과 연결된 한 문항]
- **탐구 자료:** [제시할 그림, 표, 실험 결과, 연구 대화와 묻고자 하는 것]
- **핵심 정리:** [모듈 끝에 정리할 핵심 통찰 2~3개와 전략 한 줄(`~하라.`)]
- **보충 설명 / 더 알아보기:** [필요한 경우에만, 둘을 합쳐 모듈당 최대 2개. 부가 사실이나 논문 밖 확장]
- **확인 문제:** [3~5문항, 그중 하나 이상은 부정형(`옳지 않은 것은?`) 또는 보기형. 발문은 `다음 중 ~으로 옳은 것은?` 형식, 선택지는 ①②③④]

### 대가와 실패 사례
이 모듈에서 소개하는 방법·패러다임마다 적는다. 비워 두지 않는다.
| 방법 | 단점·비용 | 실패하는 입력 예 | 출처(1차) 또는 "예시" |
|---|---|---|---|

### 지표 계산 예
이 모듈에서 처음 나오는 지표마다 작은 수치 예와 계산 결과를 적는다(그림으로 그릴 값과 같게).
- [예: 정답 문서 3개, top-5 중 2개 적중 → Precision@5 = 0.40, Recall@5 ≈ 0.67, F1 = 0.50]

### 화면별 계획 (코넬 페이지)
모든 화면은 코넬식 한 페이지이다. 페이지마다 다음을 정한다.
- **핵심 질문(`.cue`):** [2~4개, 한다체 의문형. 예: 어텐션은 무엇을 계산하는가?]
- **노트 내용(`.notes`):** [화면 제목, 코너 이름, 들어갈 본문·수식·그림·요소]
- **한 문장 요약(`.summary`):** [한다체 한 문장]
- **쪽 맞춤:** [한 페이지에 넣을 분량인가? 1440×900(내비게이션 제외 약 765px)에 스크롤 없이 들어가야 한다. 넘치면 페이지를 나눈다. 높은 SVG와 표는 높이를 적고, 퀴즈는 페이지당 4문항 이하로 나눈다]

### 이 모듈에서 쓰는 용어
코스 용어표에서 이 모듈에 쓰이는 항목만 발췌한다. 번역어를 새로 만들지 않고 용어표를 따른다. 새 용어가 필요하면 용어표에 먼저 추가한다.

| English | 한국어 표기 | 첫 등장 표기 | 처음 나오는 모듈 | 비고 |
|---|---|---|---|---|
| Policy Gradient | 정책 경사 | 정책 경사(Policy Gradient) | 모듈 3 | [툴팁 정의(사전식 명사형): 보상이 커지는 방향으로 정책 파라미터를 직접 갱신하는 최적화 방법.] |

(열은 `briefs/terms.md`와 같은 5개이다. 약어는 `한글 풀이(English Full Name, ACRONYM)` 형식으로 적는다.)

### 새 개념별 그림 목록
이 모듈에서 새로 도입하는 개념·알고리즘·수식마다 그림 하나를 정한다. 없으면 이유를 적는다.

| 개념 | 그림(무엇을 어떤 숫자로) | 배치(`.with-figure` 옆 / 문항 삽화) |
|---|---|---|
| [예: 스케일드 내적] | [예: 격자 위 쿼리·키 벡터, $d_k$ 값과 본문 숫자 일치] | [옆] |

### 첫 페이지 구성 (1단원만)
- **문제 문단:** [이전 방식의 한계와 이 논문의 동기 2~3문장]
- **비교 그림:** [이전 방식 대 제안 방식, 같은 입력, 핵심 비교]
- **새로운 점:** [3개 이내, 항목마다 이름 + 논문 수치 근거]

### 화면별 `.paper-ref`
화면마다 논문 위치를 적는다. 논문 밖 화면(배경 지식, 확장)은 `없음`으로 적고 태그를 붙이지 않는다.
- [화면 제목 → 논문 3.2.1절 / 없음]

### 페이지의 주 버튼
Space 키는 페이지의 주 버튼을 누른다. 페이지마다 주 인터랙티브 요소를 가능하면 하나만 둔다.
- [화면 제목 → 수식 유도 / 의사코드 풀이 / 확인 문제 / 없음]

### 인터랙티브 요소

이 모듈에 필요한 요소를 체크한다.
- [ ] **수식 유도 풀이** — 대상 수식, 단계 수
- [ ] **의사코드 풀이** — 대상 알고리즘
- [ ] **결과 비교** — 인터랙티브로 재현할 표/그림
- [ ] **연구 대화** — 등장인물: [목록], 주제: [논의 내용]
- [ ] **퀴즈** — [문항 수]개, 유형: [예측 / 비판적 읽기 / 설계 결정 / 추적]
- [ ] **끌어놓기** — 항목: [목록], 대상: [목록]
- [ ] **SVG 다이어그램** — 그릴 내용
- [ ] **기타** — [계보 트리, 절제 연구 토글, 개념 지도 등]

### 문체 확인 항목
작성을 마친 뒤 다음을 확인한다.
- [ ] 본문, 학습 목표, 해설이 한다체이다. `~합니다`, `~해요`, `여러분`, 느낌표가 없다.
- [ ] 학습 목표가 `~할 수 있다.`로 끝난다.
- [ ] 발문이 `다음 중 ~은?` 형식이고 선택지에 ①②③④가 붙어 있다.
- [ ] 해설이 `~이므로 ~이다.` 형식이고 칭찬이 없다. 오답 해설에는 `①은 ~이므로 옳지 않다.` 형식의 오답지 분석이 한 줄 있다.
- [ ] 용어가 코스 용어표와 일치하고, 첫 등장 시 툴팁이 `한글 용어(English Term): ~하는 값.` 같은 사전식 명사형 정의이다(KO111). 핵심 정리 끝에 `~하라.` 전략 한 줄이 있다. 모듈 제목·번호가 논문 절을 따른다.
- [ ] 번역투(`~에 의해`, `~를 가지고 있다`, `~되어진다`)가 없다.
- [ ] 약어와 수식 뒤 조사가 읽는 소리에 맞는다.
- [ ] 괄호가 반각이고 한자나 중국어가 없다.
- [ ] `python3 references/lint-ko.py <course-dir>`를 통과한다.
