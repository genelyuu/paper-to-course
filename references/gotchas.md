# 1부. 구조와 콘텐츠

### 툴팁 잘림
- 번역·수식 블록 안 툴팁이 잘린다 / 블록이 `overflow: hidden`인데 툴팁이 `position: absolute` / `position: fixed` + `document.body`에 붙인다(`main.js`가 처리).

### 툴팁 부족
- 낯선 용어·기호(특히 수학 기호)가 설명 없이 나온다(가장 흔함) / 학습자가 안다고 가정 / 일상 대화에 안 나올 용어는 모두 툴팁. 형식은 `정책 경사(Policy Gradient): ~ 방법.` 사전식 명사형. (KO107, KO111)

### 직관 없는 수식
- 수식만 제시 / 곧바로 보여 주려 함 / (1) 앞에 직관 문장, (2) 수식, (3) 뒤에 왜 중요한지.

### 맥락 없는 결과
- "정확도 78.3%"만 / 숫자 의미 미설명 / 좋은 값인지, 비교 대상, 상한을 밝힌다. 모든 결과 수치에 비교 기준.

### 글 벽
- 시각 요소 없이 2~3문장 넘게 이어짐 / 서술로만 전달 / 화면 절반 이상을 시각 요소로. 항목 3개 이상은 카드, 순서는 단계 카드·흐름도. (KO106)

### 선수 개념 건너뛰기
- 모듈 1 이후 KL 발산 등이 설명 없이 나옴 / 안다고 가정 / 모듈 0(id 기준 첫 모듈, 화면 번호 1)에서 가르치거나 툴팁으로 설명.

### 논문 그림 누락
- 논문 구조도(그림 1)·핵심 결과 그래프가 강의에 없음 / 그림 목록 없이 본문만 따라 씀 / Phase 1에서 `briefs/figures.md`에 모든 그림·표를 적고 모듈에 배정. 빌드 뒤 `grep -o '논문 그림 [0-9]*' modules/*.html | sort -u`로 대조.

### 논문을 무오류로 취급
- 성과만 칭송 / 비판적 읽기 미적용 / 한계(단일 데이터셋, 오차 범위 내 개선 등)를 밝힌다.

### 인용 남발
- 관련 논문 15편 나열 / 선별 없음 / 3~5편만 `.paper-citation` 카드에 한 문장 요약과 함께.

### KaTeX 렌더링 실패
- 수식이 원문 그대로 / `\begin{align}`(자동 렌더링 미지원), 단일 `$` 충돌(인라인 수식 앞뒤 공백 필요) / `$$...$$` 안에서 `aligned`. `\mathbb`는 기본 지원.

### 본문의 달러 기호가 수식으로 바뀜
- "US$17.30 … US$12" 사이가 수식으로 깨짐 / 자동 렌더링이 `$`를 구분자로 읽음 / `17.30달러`, `USD 17.30`. 꼭 필요하면 `\$` 말고 `&#36;`, 같은 문단에 다른 `$` 없게.

### 코드 글꼴에서 기호가 다르게 보임
- 의사코드·`<pre>`의 `∅`가 `ø`, `⋆`가 점처럼 / JetBrains Mono·대체 글꼴 글리프 차이 / `$\emptyset$`, `$\star$`처럼 KaTeX로, 또는 `{}`·`*` ASCII로 바꾸고 첫 등장에 뜻을 단다.

### 도식 글자가 너무 작음
- 축소된 SVG 라벨이 10~11px / 가로 800 viewBox를 좁은 칸(`.with-figure` 옆 등)에 넣음 / 렌더링 라벨 12px 이상: `font-size × (표시 폭 ÷ viewBox 폭) ≥ 12`. 그림을 줄이지 말고 상자 수를 줄이거나 두 쪽으로 나누고, 세부는 표로.

### 드래그 칩 안 수식이 보이지 않음
- 교과 색 칩 위 `<i class="mi">θ</i>`가 같은 색 / 수학 기호 교과 색 규칙이 칩 안에도 적용 / 현재 `styles.css`는 칩·칸 안 기호가 둘레 글자색을 따른다. 넣은 뒤 렌더링해 확인.

### 원문 HTML·임시 HTML이 린터에 걸림
- `_src/`의 arXiv HTML이나 `_tmp/` 스크린숏용 HTML로 lint ERROR / `lint-ko.py`는 밑줄로 시작하는 폴더와 `vendor/`를 건너뛴다. 원문·임시 파일은 반드시 `_src/`, `_tmp/` 아래에.

### 코드 같은 의사코드
- Python·C++처럼 보임 / 특정 언어 문법 / 언어 중립: `입력`, `출력`, `각 항목에 대해`, `만약 ~이면`.

### 페이지 넘침
- 1440×900 한 화면을 넘어 스크롤, `check-pages.py`가 `OVER` / 내용 과다, 퀴즈 2문항 초과, 큰 SVG / 글을 줄이지 말고 여러 `.screen.cornell`로 나눈다(페이지마다 핵심 질문·요약). 퀴즈는 `.quiz-container`를 나눠 고유 id와 자기 버튼. SVG는 `viewBox` 유지한 채 높이 제한. 재실행: `python3 -I <skill-dir>/references/check-pages.py <course-dir>`. 기준 765px(813px − 48px). 짧은 페이지에서 요약이 맨 아래인 것은 의도된 동작(`--page-height` 최소 높이).

### 배치 문제(LAY)
- `check-pages.py`가 `LAY` 보고, 종료 코드 1. 검사: ① 화면·본문 칸 가로 넘침, ② `overflow: hidden/clip` 상자에 잘린 내용, ③ 상자 안 가로 스크롤, ④ SVG 밖 `<text>`(SVG `overflow`가 visible 아닐 때), ⑤ 25% 넘게 겹친 SVG 글자, foreignObject 밖으로 2px 넘게 나간 라벨, ⑥ 색 없는 코드 줄(`pre`, `.pseudocode-line`), ⑦ 페이지 가로 스크롤, ⑧ 말줄임된 사이드바 라벨.
- 해결: 그림 폭(`--diagram-max`)·표(`.data-table.compact`) 축소, 라벨 함축, SVG 글자를 `viewBox` 안으로. 색 없는 코드 줄은 키워드 대문자(`RETURN`, `FOR`)로 쓰거나 앞 줄에 붙인다.

### 측정 스크립트에서 SVG 회전이 사라짐
- 직접 만든 측정·캡처에서 세로 축 제목이 SVG 밖으로 나간 듯 / `.animate-in *{transform:none}`이 SVG `rotate()`까지 지움 / `.animate-in, .animate-in *:not(svg, svg *)`(`check-pages.py`는 이미 그렇게 함). 헤드리스 창 높이는 900(813으로 주면 726px이 되어 `용어 정리`가 빠짐).

### 코넬 아닌 화면
- `check-pages.py`가 `코넬 아닌 화면` 보고 / 모든 `.screen`을 `.screen.cornell`로, `.cue`·`.notes`·`.summary`를 갖춘다.

### 문항 번호 이중 표기
- 번호가 `1` 블록과 `1.` 텍스트로 두 번 / `q-num`과 `1. ` 텍스트를 함께 씀 / `<span class="q-num">`만, `[3점]`은 `<span class="q-points">`.

### 스크롤 스냅 mandatory
- 긴 모듈에 갇힘 / `scroll-snap-type: y mandatory` / 항상 `proximity`.

### 모듈 품질 저하
- 뒤 모듈일수록 부실 / 한 번에 모두 작성 / 하나씩 작성, 복잡한 논문은 모듈 브리프 병렬 경로.

### 인터랙티브 요소 누락
- 텍스트·수식만 있는 모듈 / 계획 안 함 / 모듈마다 퀴즈, 데이터 흐름 애니메이션, 연구 대화, 수식 유도, 의사코드 풀이, 결과 비교 중 하나 이상.

### SVG가 반응형이 아님
- 폭이 바뀌면 잘림 / `viewBox` 없음 또는 픽셀 고정 / `viewBox="0 0 W H"` + `width="100%"`, 높이 고정 안 함.

### 표지 누락
- 제목·저자·초록·메타데이터 없이 시작 / 모듈 앞에 `_cover.html` 히어로 영역.

### 모듈 0(선수 개념) 누락
- 선수 개념 없이 논문 문제로 직행 / 선수 학습 모듈(id·파일 `module-0`/`00-`, 화면 번호 1, 논문 절 아님) 필수. "호기심 많은 실무자"에게 필요한 기초를 가르친다.

### 목차 번호가 연속 정수가 아니거나 논문 위치가 없음
- `.module-number`가 `3.2`, `1–2`, `0`, `01`; 화면 제목 앞 `.sec-num`; `.module-title`이 "핵심 아이디어: …" 식.
- 해결: 배지, 표지 `toc-num`, 사이드바 `sidebar-item-num`, 내비 점 툴팁·`aria-label`(`2단원 어텐션`) 모두 `1, 2, 3 …`. 제목은 논문 절 제목의 한국어 번역. 논문 위치는 화면 제목 끝 `<span class="paper-ref">논문 3.2.1절</span>`만, `.sec-num` 금지. `id="module-N"`과 파일명(`00-`, `01-`)만 0부터.

### 방향키가 페이지 단위로 동작하지 않음
- ←/→가 이상하거나 무반응, `.pager` 안 보임 / `initPager()`가 페이지 단위(표지, 모듈 첫 페이지, 각 `.screen`)로 처리하는데 다른 `keydown` 핸들러가 `preventDefault`하거나 옛 모듈 단위 핸들러가 남음 / 방향키(←↑→↓, PageUp/PageDown, Home/End)·Space·Shift+Space를 가로채는 핸들러를 추가하지 않는다(Space = 현재 페이지 주 버튼, 할 일이 없으면 다음 페이지). `.pager` 마크업은 쓰지 않는다(JS가 넣음).

### 사이드바 동기화 실패
- 활성 항목이 안 바뀌거나 클릭 이동 안 됨 / 항목을 모듈과 1:1(nav-dots와 같은 순서)로, `updateProgress()`에서 `updateSidebar()` 호출.

### 표지에 `.module` 클래스 사용
- nav-dot·사이드바 대응 어긋남 / 둘 다 `$$('.module')`로 찾음 / 표지는 `.course-cover`.

# 2부. 한국어 출력

### 출력 언어 불일치
- 다른 언어가 섞이거나 `<html lang>`이 `ko`가 아님 / 원문·예시 언어를 따름 / 기본 한국어, 사용자가 명시할 때만 변경. 전문 용어만 괄호 안 영어 병기. (KO001)

### 문체 혼용
- 한다체에 `~합니다`·`~해요`, `여러분`, 느낌표, 수사 의문문 / 모듈·하위 에이전트마다 기준이 다름 / 본문·학습 목표·해설은 한다체. 학습 목표 `~할 수 있다.`, 지시문 `~하시오.`. 연구 대화 대사만 구어체. (KO102, KO109)

### 번역투
- `~에 의해 ~되어진다`, `~를 가지고 있다`, `~에 있어서`, 불필요한 `~들`, 무생물 주어 / 영어 구조 그대로 / 능동으로: `섀튼 교수에 의해 작성되었다` → `섀튼 교수가 썼다`, `~를 가지고 있다` → `~이 있다`, `실험을 통해` → `실험으로`, `발전되었다` → `발전하였다`. 이중 피동 금지, 수학 피동(`정의된다`, `주어진다`)은 허용. 한 문장 한 주장. (KO101)

### 용어 불일치
- 같은 개념이 모듈마다 다른 번역어(`보상`/`리워드`) / 용어표를 안 봄 / 3단계에서 용어표 확정, 모든 브리프에 발췌. 새 번역어는 용어표에 먼저. 굳은 음차(트랜스포머, 어텐션)는 관용 표기.

### 약어 뒤 조사 오류
- `GPT이`, `LoRA을` / 철자로 받침 판단 / 발음 기준: `LoRA를`(로라), `GPT가`(지피티), `RLHF가`(알엘에이치에프), `PPO를`(피피오). 어려우면 `GPT 모델은`. (KO104)

### KaTeX 수식 뒤 조사
- `$x$은` 등 어색 / 읽는 소리 미고려 / `$x$는`(엑스), `$y$는`(와이), `$\theta$를`(세타), `$\alpha$가`(알파). 긴 수식은 `$L$의 값은`, `수식 (3)은`. (KO104)

### 해설의 정답/오답 표지 중복
- `정답 정답. ~이다.` / `main.js`가 `정답`/`오답`을 자동으로 붙이는데 해설에도 씀 / 표지 없이: `data-explanation-right="② | ~이다."`, `data-explanation-wrong="| 정답은 ②이다. ~이다. ①은 ~이므로 옳지 않다."`. (KO110)

### 숫자와 단위 띄어쓰기
- `78.3 %`, `5 배`, `3개`/`3 개` 혼재 / 규칙 미통일 / 아라비아 숫자 뒤 한글 단위(`개`, `배`, `번`, `명`, `분`, `단계`, `가지`)는 붙인다(맞춤법 제43항 허용 규정). `%`·`%p`·`°` 붙임(`78.3%`, `2.1%p`). 라틴 SI·컴퓨팅 단위는 한 칸(`3 kg`, `10 ms`, `16 GB`). (KO105)

### 괄호 간격과 전각 문장 부호
- `정책 경사 (Policy Gradient)`, `（ ）`·`，`·`。`·`：` / 중국어·일본어 예시나 옛 템플릿 / 반각 `( )`, 앞 공백 없음, `,` `.`. (KO003, KO103)

### 한자·중국어 잔존
- 한자·중국어 문장이 남음(원문·예시가 중국어일 때 잦음) / 예시 모방, 미번역 인용 / 한글로 옮기고 인용은 번역. 한자는 근거와 함께 의도적 예외 목록에 올린 경우만. (KO002)

### 한글 SVG 라벨 잘림
- 한글 라벨이 박스 밖으로 넘침 / 라틴 폭(0.55em)으로 계산 / 폭 ≥ 글자 수 × 1em. 상자 안 라벨은 `<foreignObject>` 안 `<div class="node-label"><span>…</span></div>`, `<text>`는 상자 밖 짧은 표지만(`design-system.md` 그림 정렬 규칙).

### `keep-all`로 인한 긴 영문 토큰 넘침
- 모바일에서 긴 영문·URL이 가로 스크롤 / `word-break: keep-all` / `styles.css`의 `overflow-wrap`에 맡기고 `<br>`을 넣지 않는다.

### `<em>` 이탤릭 기대
- `<em>`이 굵게·강조색으로 보임 / 한글 가짜 기울임 방지 스타일 / 강조 용도로만. 기울임이 꼭 필요하면(영어 논문 제목) 라틴 구간에만.

### 퀴즈 피드백에 칭찬·격려
- `정답이에요!`, `훌륭해요`, `아쉬워요` / `정답`/`오답` 뒤에 `~이므로 ~이다.` 한다체 해설만. (KO108)


## 그림 정렬이 어긋남
- 막대가 라벨 길이에 따라 다른 x에서 시작, SVG 상자 글자가 위에 붙음, `d<sub>k</sub>`가 세 조각, 간선이 허공에서 끝남, 의사코드 줄과 설명 줄이 점점 어긋남 / 내용 따라 폭이 변하는 flex, span 없는 `foreignObject` flex 가운데 정렬, 손 좌표, 단락 여백이 부품 안으로 샘 / `design-system.md` 그림 정렬 규칙: 막대는 subgrid, 라벨 `.node-label > span`, 좌표는 폭 공식, 간선은 노드 테두리에서 끝. `check-pages.py`가 검사.

## 도식 간선이 대각선임
- `<line>`이 비스듬하고 선이 엇갈림 / 노드 중심을 곧장 이음 / `<path class="edge-line" d="M400,80 V115 H200 V140"/>` + 화살촉 `<polygon>`. 노드는 옮기지 않는다("도식 간선은 직각으로").

## 수식이 똑바른 글꼴임
- `clip`, `mean`, 아래첨자 `ref`, 벡터 `q`가 똑바름 / `\text{}`, `\mathrm{}`, `\mathbf{}`, `\operatorname{}` / `\mathit{clip}`, `L_{\mathit{GRPO}}`, 벡터 `\boldsymbol{q}`. (KO112, `korean-style-guide.md` §7)

## 도식 라벨의 `<i>`에 `.mi`가 없음
- 노드 안 `q`, `d`가 똑바른 한글 글꼴 / 한글 규칙이 `<i>`를 `font-style: normal`로 / `<i class="mi">q</i>`(`<text>`는 `font-style="italic"`).

## 새 개념인데 그림이 없음
- 새 개념·알고리즘·수식이 글로만 / 개념마다 코드로 그린 그림 하나, 숫자는 본문과 같게, `.with-figure` + `figure.figure.side`. 브리프 "새 개념별 그림 목록"에서 미리 정한다.

## `.paper-ref`를 논문 밖 화면에 붙임
- 배경 지식·확장 화면에도 `논문 3.2절` / 논문의 해당 절에서 온 화면에만 붙인다.

## 색상 규약 위반
- 교과 색 외 유채색, 베이지·크림 면, 색·굵게·밑줄 중복, 명암비 4.5:1 미만 / `design-system.md` "색상 규약": 그림은 먹색 + 교과 색 + 회색, 상태 색은 정답·오답 피드백만, 코드 색은 `main.js` 자동 색칠만. `check-pages.py`가 그림당 유채색 1개 초과 검출.

## 화면 제목 안의 기호가 띄어 보임 ("top- k")
- 제목의 수식·`<i class="mi">` 앞뒤가 크게 벌어짐("top-   k 와"), 본문 `top-$k$`도 KaTeX가 하이픈 뒤를 띄움 / `.screen-heading`이 `display: flex` + `gap`이라 조각마다 flex 항목 / 제목 글자를 span 하나로: `<h3 class="screen-heading"><span>top-<i class="mi">k</i>와 MIPS</span><span class="paper-ref">…</span></h3>`. 본문에서 하이픈에 붙는 기호는 `top-<i class="mi">k</i>`. 속성값(`data-definition` 등)엔 HTML 없이 `top-k`.
