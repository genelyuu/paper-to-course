공통 언어 런타임(CLR)의 기술 개요

Technical Overview of the Common Language Runtime

여러 프로그래밍 언어가 함께 쓰도록 처음부터 설계한 가상 머신 CLI의 구조, 명령어, 타입 시스템을 JVM과 비교하며 익힌다

Erik Meijer (Microsoft), John Gough (Queensland University of Technology)

2001 모듈 8개 약 55분 중급
초록

Microsoft .NET의 기능은 공통 언어 기반(CLI) 위에 서 있다. CLI는 다른 가상 머신과 달리 처음부터 여러 프로그래밍 언어를 지원하도록 설계되었다. 이 논문은 CLI의 구조, 명령어 집합, 타입 시스템을 짧게 설명하고, Java가 아닌 언어를 올리기 어려운 JVM과 비교해 CLI가 더 나은 다중 언어 실행 환경인 지점을 짚는다.
