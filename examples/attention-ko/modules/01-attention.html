3.2.1스케일드 내적 어텐션

각 위치는 다른 위치의 정보를 어떻게 가져올까? 트랜스포머의 핵심은 스케일드 내적 어텐션(scaled dot-product attention)이다. 각 위치가 쿼리를 던지고, 모든 위치의 키와 비교하여 얻은 비중으로 값을 섞는다.

요약

스케일드 내적 어텐션은 내적, 크기 조정, 소프트맥스, 값 섞기의 네 단계로 출력을 만든다.

용어
$Q$, $K$, $V$
쿼리, 키, 값 행렬
$d_k$
키 벡터의 차원
$S$
점수 행렬
$W$
비중 행렬

탐구 자료수식 유도 단계별 풀이

어텐션 식을 한 단계씩 쌓아 올린다. 버튼을 눌러 다음 단계를 보시오.

$$\mathrm{Attention}(Q, K, V) = \mathrm{softmax}\!\left(\frac{QK^{\top}}{\sqrt{d_k}}\right)V$$

어텐션의 출력은 쿼리와 키로 만든 비중을 값에 곱한 결과이다. 여기서 $Q$는 쿼리 행렬(matrix), $K$는 키 행렬, $V$는 값 행렬, $d_k$는 키 벡터의 차원(dimension)이다.

$$S = QK^{\top}$$

키 행렬을 전치(transpose)하여 곱하면 모든 쿼리와 모든 키의 내적이 한 번에 나온다. 점수 행렬 $S$의 $i$행 $j$열은 $i$번째 쿼리와 $j$번째 키의 내적이다.

$$\mathbf{q}\cdot\mathbf{k} = \sum_{m=1}^{d_k} q_m k_m, \qquad \mathrm{Var}(\mathbf{q}\cdot\mathbf{k}) = d_k$$

$\mathbf{q}$와 $\mathbf{k}$의 각 성분이 평균 0, 분산(variance) 1인 독립 확률 변수라고 가정하면 내적의 분산은 $d_k$가 된다. 차원이 클수록 점수의 흩어짐이 커진다.

$$\frac{S}{\sqrt{d_k}} \;\Rightarrow\; \mathrm{Var}\!\left(\frac{\mathbf{q}\cdot\mathbf{k}}{\sqrt{d_k}}\right) = \frac{d_k}{d_k} = 1$$

점수를 $\sqrt{d_k}$로 나누면 분산이 다시 1이 된다. 점수가 너무 커지면 소프트맥스가 한 위치로 쏠려 기울기가 매우 작아지므로, 이 조정으로 학습이 안정된다.

$$W = \mathrm{softmax}\!\left(\frac{S}{\sqrt{d_k}}\right), \qquad \mathrm{Attention}(Q,K,V) = WV$$

소프트맥스를 행마다 적용하면 각 쿼리의 비중 행이 만들어지고, 한 행의 합은 1이다. 이 비중 행렬 $W$를 값 행렬 $V$에 곱하면 값을 비중대로 섞은 출력이 나온다.

요약

어텐션은 점수 행렬을 $\sqrt{d_k}$로 나누고 소프트맥스를 적용한 비중으로 값을 섞는다.

핵심 질문
  • 내적의 분산은 차원과 어떤 관계인가?
  • 점수가 너무 크면 학습에 어떤 문제가 생기는가?

개념 체크크기 조정의 이유

각 성분이 평균 0, 분산 1인 독립 확률 변수이면 내적의 분산은 $d_k$이다. 점수를 $\sqrt{d_k}$로 나누면 분산이 다시 1이 된다.

1다음 중 내적을 나누지 않고 키 차원 $d_k$를 크게 할 때 나타날 결과로 가장 타당한 것은?

요약

내적을 $\sqrt{d_k}$로 나누면 분산이 1로 돌아와 소프트맥스가 한 위치로 쏠리지 않는다.

핵심 질문
  • 점수 행렬은 어떻게 한 번에 구하는가?
  • 소프트맥스는 어느 단위로 적용하는가?

탐구 자료의사코드 단계별 풀이

같은 계산을 줄 단위로 따라가 본다. 각 줄이 앞의 유도 단계와 어떻게 대응하는지 확인하시오.

알고리즘 INPUT: Q, K, V, d_k // 입력 S = MATMUL(Q, TRANSPOSE(K)) // 점수 S = S / SQRT(d_k) // 크기 조정 FOR EACH 행 r OF S DO // 쿼리마다 반복 W[r] = SOFTMAX(S[r]) // 비중 만들기 END FOR // 반복 끝 OUTPUT: MATMUL(W, V) // 값 섞기
설명

입력은 쿼리, 키, 값 행렬과 키 차원이다.

모든 쿼리와 모든 키의 내적을 한꺼번에 구한다. 반복문 없이 행렬 곱 한 번으로 끝난다.

내적의 분산을 1로 되돌리려고 키 차원의 제곱근으로 나눈다.

각 쿼리의 점수 행을 하나씩 처리한다.

점수 행에 소프트맥스를 적용하여 합이 1인 비중을 만든다.

반복을 마친다.

비중 행렬을 값 행렬에 곱하여 출력을 얻는다. 비중이 큰 위치의 값이 더 많이 섞인다.

요약

의사코드는 행렬 곱, 크기 조정, 행별 소프트맥스, 값과의 곱 순서로 어텐션을 계산한다.

💡
보충 설명

논문은 어텐션을 세 곳에 쓴다. 인코더의 셀프 어텐션(self-attention), 디코더의 셀프 어텐션, 디코더가 인코더 출력을 참고하는 인코더-디코더 어텐션이다.

3.2.2멀티헤드 어텐션

멀티헤드 어텐션(multi-head attention)은 어텐션을 한 번만 계산하지 않고 $h$개의 헤드로 나누어 계산한다. 각 헤드는 학습된 서로 다른 선형 변환으로 쿼리, 키, 값을 낮은 차원으로 옮긴 뒤 어텐션을 수행한다.

$$\begin{gathered}\mathrm{MultiHead}(Q,K,V) = \mathrm{Concat}(\mathrm{head}_1, \ldots, \mathrm{head}_h)\,W^O \\ \mathrm{head}_i = \mathrm{Attention}(QW_i^Q,\, KW_i^K,\, VW_i^V)\end{gathered}$$

여기서 $W_i^Q$, $W_i^K$, $W_i^V$는 헤드 $i$의 투영 행렬이고 $W^O$는 이어 붙인 결과를 되돌리는 행렬이다. 모델 차원이 $d_{\text{model}}=512$이고 헤드가 $h=8$개이면 각 헤드의 차원은 $d_k = d_v = 512/8 = 64$이다.

1
투영

헤드마다 다른 행렬로 쿼리, 키, 값을 차원 64로 옮긴다.

2
병렬 어텐션

헤드 8개가 각자 스케일드 내적 어텐션을 동시에 계산한다.

3
이어 붙이기

헤드 8개의 출력을 이어 붙이면 차원 512가 되고, $W^O$를 곱해 최종 출력을 만든다.

요약

멀티헤드 어텐션은 차원 512를 헤드 8개로 나누어 차원 64의 어텐션을 병렬로 계산한다.

💡
핵심 정리
  1. 어텐션은 쿼리와 키의 내적으로 비중을 만들고 그 비중으로 값을 섞는다.
  2. 내적을 $\sqrt{d_k}$로 나누면 분산이 1로 유지되어 소프트맥스가 한쪽으로 쏠리지 않는다.
  3. 멀티헤드 어텐션은 $d_{\text{model}}$을 $h$개 헤드로 나누어 서로 다른 관점을 병렬로 학습한다.
  4. 나누는 값을 묻는 문항은 분산이 아니라 그 제곱근인지 확인하라.

확인 문제크기 조정과 계산 과정

1키 차원이 $d_k = 64$일 때 내적 점수를 나누는 값은?

2스케일드 내적 어텐션의 계산 과정에 대한 설명으로 옳지 않은 것은?

요약

키 차원이 64이면 점수를 8로 나누고, 비중 행렬의 각 행은 합이 1이다.

핵심 질문
  • 헤드마다 투영 행렬이 같은가?
  • 헤드 하나의 차원은 어떻게 정해지는가?

확인 문제멀티헤드 어텐션

3멀티헤드 어텐션에 대한 설명으로 옳은 것만을 <보기>에서 있는 대로 고른 것은?[3점]

ㄱ. 내적을 $\sqrt{d_k}$로 나누어 소프트맥스 입력이 지나치게 커지는 것을 막는다.

ㄴ. 모든 헤드가 같은 투영 행렬을 공유한다.

ㄷ. $d_{\text{model}}=512$, $h=8$이면 각 헤드의 차원은 64이다.

요약

멀티헤드 어텐션은 헤드마다 서로 다른 투영 행렬을 쓰고, 헤드 하나의 차원은 $d_{\text{model}}/h$이다.
