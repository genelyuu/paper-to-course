이전 연구와 한계

RAG 이전의 세 갈래 접근과 각각의 한계, 그리고 RAG가 합친 것을 따라간다

학습 목표

이 모듈을 학습하면 다음을 할 수 있다.

  1. closed-book, retrieve-and-extract, memory network 방식의 한계를 각각 설명할 수 있다.
  2. RAG가 이전 연구에서 이어받은 것과 새로 합친 것을 구분할 수 있다.
  3. 지식 갱신, 근거 제시, 생성 가능 기준으로 네 접근을 비교할 수 있다.

지식을 다루는 세 갈래논문 1·5절

RAG 이전의 모델은 지식을 어디에 두었을까? 이전 연구는 지식을 두는 곳과 답을 내는 방식에 따라 세 갈래로 나눌 수 있다. 그림은 세 갈래와 검색 증강 생성(Retrieval-Augmented Generation, RAG)이 각 갈래에서 가져온 것을 나타낸 것이다.

①은 parametric memory(모델 파라미터에 저장된 기억)만, ②는 주로 non-parametric memory(외부 문서 색인에 있는 기억)를 쓴다. 세 갈래는 저마다 한 가지씩을 잘했지만 한계도 뚜렷했다. 이 단원은 갈래마다 대표 연구와 한계를 본 뒤, RAG가 이들을 어떻게 묶었는지 정리한다.

요약

이전 연구는 closed-book, retrieve-and-extract, memory network 계열로 나뉘고 RAG는 각각에서 한 가지씩을 가져왔다.

핵심 질문
  • closed-book과 open-book은 무엇이 다른가?
  • LAMA와 T5는 무엇을 보였는가?

① closed-book: 파라미터에서 답을 꺼낸다논문 1절

closed-book(클로즈드북, 외운 지식만으로 답하기)은 시험에서 책을 덮고 외운 것만으로 답하는 방식이다. 반대로 open-book(오픈북, 자료를 찾아 읽고 답하기)은 그림처럼 책을 펴 놓고 찾아 읽으며 답한다.

LAMA(Petroni et al., 2019)는 사전학습 언어 모델(Pre-trained Language Model)이 빈칸 질의만으로 사실 지식을 꺼낼 수 있음을 보였다. T5 closed-book QA(Roberts et al., 2020)는 T5(Text-to-Text Transfer Transformer)를 질문과 답으로 fine-tuning(미세 조정)해 검색 없이 답하게 했다.

그림은 두 연구가 같은 사실을 묻는 과정을 나타낸 것이다. 질의와 답은 예시이다.

요약

LAMA와 T5는 사전학습 모델이 문서 없이 파라미터만으로 사실을 답할 수 있음을 보였다.

핵심 질문
  • closed-book 방식의 세 한계는 무엇인가?
  • 파라미터를 늘리면 해결되는가?

탐구 자료closed-book의 한계논문 1절, 표 1, 부록 G

closed-book 모델이 더 많이 알게 하려면 파라미터를 늘려야 한다. 그래프는 오픈 도메인 질의응답(Open-Domain QA) 벤치마크 NQ(Natural Questions)의 테스트 EM(exact match, 완전 일치)을 모델별로 나타낸 것이다. 괄호 안은 파라미터 수이며 RAG는 학습하는 파라미터만 센 값이다.

표는 parametric memory만 쓰는 모델의 세 한계를 나타낸 것이다. 환각 예는 BART의 실제 출력이다(논문 표 3).
한계무엇이 문제인가예

환각(Hallucination)그럴듯하지만 틀린 문장“The middle ear is the part of the ear between the middle ear and the nose.”
요약

closed-book은 파라미터를 키워야 지식이 늘고, 갱신 불가, 근거 불명, 환각이라는 한계가 남는다.

② retrieve-and-extract: 찾아서 잘라 낸다논문 1·5절

retrieve-and-extract(검색한 뒤 답 구간 추출)는 retriever(검색기)로 문서를 찾고, reader(검색 문서에서 답을 읽어 내는 모델)가 문서 속 답 구간을 그대로 잘라 낸다. 이렇게 답을 고르는 방식을 추출형(Extractive, 문서에서 답 구간을 골라냄)이라 한다. 그림의 질문과 문서는 예시이다.

표는 retrieve-and-extract 계열의 대표 연구 네 편을 나타낸 것이다.
연구retriever특징과 대가
DrQA(2017)위키백과 TF-IDF 검색검색은 학습하지 않고 추출형 reader만 학습함
ORQA(2019)학습하는 검색검색을 잠재 변수(Latent Variable)로 두고 학습함
REALM(2020)학습하는 검색검색을 넣은 MLM(Masked Language Model) 사전학습, 사전학습 중 색인을 주기적으로 다시 만들어 비용이 큼, salient span masking(SSM) 사용
DPR(2020)bi-encoder dense 검색BM25를 넘어섬, QA 시스템은 cross-encoder reranker와 추출형 reader를 더 씀
요약

retrieve-and-extract는 검색한 문서에서 답 구간을 잘라 내며, 검색을 학습하는 방향으로 발전했다.

핵심 질문
  • 답이 문서에 그대로 없으면 추출형은 어떻게 되는가?
  • 추출형으로 풀 수 없는 과제는 무엇인가?

탐구 자료추출의 한계논문 1절, 4.1절

추출형은 문서에 있는 글자만 답으로 낼 수 있지만, 생성형(Abstractive, 답을 새로 써냄)은 답을 새로 쓴다. 그림은 질문 “신곡을 쓴 시인은?”에 대해 정답 단어가 없는 문서를 받은 두 방식을 비교한 예시이다.

논문은 검색한 문서 어디에도 정답이 없는 경우에도 RAG가 NQ에서 11.8%를 맞혔고, 같은 경우 추출형은 0%라고 보고한다. 또 답이 문장이거나 질문인 과제에서는 잘라 낼 구간 자체가 없다.

표는 이 논문이 다루는 과제의 출력 형태를 나타낸 것이다. 마지막 열은 출력 형태에서 해석한 것이다.
과제원하는 출력추출형으로
NQ 등 오픈 도메인 QA짧은 답답이 문서에 있으면 가능
MS MARCO문장으로 된 답새 문장을 써야 해 어려움
Jeopardy 질문 생성개체를 가리키는 질문 문장문서에 없는 질문이므로 불가
요약

추출형은 문서에 그대로 있는 구간만 답할 수 있어, 단서만 있는 문서나 생성 과제에서 막힌다.

개념 체크③ memory network와 retrieve-and-edit논문 1·5절

memory network(외부 기억을 읽고 쓰는 신경망, Weston et al., 2014)는 외부 기억을 두었으나 과제마다 처음부터 학습했고 기억이 벡터였다. retrieve-and-edit(비슷한 예를 찾아 고쳐 쓰기)는 비슷한 학습 쌍 하나를 찾아 고쳐 쓴다. 그림은 두 방식을 나타낸 것이다.

1RAG의 기억이 memory network의 기억과 다른 점으로 옳은 것은?

요약

memory network는 과제별로 학습한 벡터 기억을, retrieve-and-edit는 비슷한 예 하나를 썼고, RAG는 사전학습된 원문 텍스트 기억을 쓴다.

핵심 질문
  • RAG는 각 선행 연구에서 무엇을 이어받았는가?
  • 무엇이 달라졌는가?
새로운 점

REALM과 ORQA는 검색을 추출형 QA에만 붙였고, RAG는 이를 “NLP의 일꾼”인 seq2seq(Sequence-to-Sequence) 전반으로 넓혔다.

탐구 자료연구 계보논문 1·5절

RAG 본 논문(2020) 사전학습 retriever + generator를 end-to-end로
생성기 계승
BART(2019)

사전학습 seq2seq generator. → 검색한 문서를 입력에 이어 붙여 지식을 보탠다.

검색기 계승
DPR(2020)

사전학습 dense retriever와 위키백과 색인. → 추출형 reader 대신 generator가 답을 쓴다.

잠재 검색
REALM·ORQA

검색을 잠재 변수로 학습한다. → seq2seq 과제 전반으로 넓히고 색인은 고정한다.

출발점
DrQA(2017)

위키백과 검색 + 추출형 reader. → 검색을 학습하고 답을 생성한다.

지식 확인
LAMA·T5

파라미터에 지식이 든다. → 부족한 지식을 검색으로 보탠다.

외부 기억
memory network

외부 기억을 읽는다. → 원문 텍스트 기억을 사전학습으로 미리 채운다.

요약

RAG는 BART와 DPR을 이어받고, REALM·ORQA의 잠재 검색을 seq2seq 전반으로 넓혔다.

핵심 질문
  • RAG는 무엇을 하나로 묶었는가?
  • 네 접근은 지식 갱신과 생성에서 어떻게 다른가?
  • RAG의 대가는 무엇인가?
더 알아보기

대가도 있다. 문서 인코더를 고정해 색인은 학습으로 나아지지 않고(4단원), 일부 과제에서는 retriever가 입력과 무관하게 같은 문서만 찾는 retrieval collapse가 생긴다(6단원).

그래서 RAG는 무엇을 합쳤나논문 1·2절

RAG는 사전학습한 retriever와 사전학습한 generator(생성기)를 확률 모델 하나로 묶는다. 검색한 문서를 잠재 변수로 보고 주변화(Marginalization)하므로, 어느 문서를 찾아야 하는지 알려 주지 않아도 end-to-end 학습(입력부터 출력까지 한 번에 학습)을 할 수 있다(3단원).

표는 네 접근을 네 기준으로 비교한 것이다. 셀은 논문 1·5절의 서술을 요약한 것이다.
접근지식 갱신근거 제시생성 가능사전학습 필요
closed-book다시 학습어려움가능대규모 사전학습, SSM으로 향상
retrieve-and-extract색인 수정추출한 문서 구간불가(추출만)REALM은 검색 사전학습과 SSM
memory network벡터라 고치기 어려움어려움과제별 구조없음, 과제마다 처음부터
RAG색인 교체검색한 문서가능기존 DPR·BART를 fine-tuning만

핵심 비교 closed-book은 생성하지만 고치지 못하고, retrieve-and-extract는 고칠 수 있지만 생성하지 못하며, RAG는 사전학습된 두 부품을 묶어 둘 다 얻는다.

요약

RAG는 사전학습 retriever와 generator를 주변화로 묶어 갱신, 근거, 생성을 함께 얻되 고정 색인과 retrieval collapse라는 대가를 진다.

핵심 정리
  1. closed-book은 파라미터를 키워야 지식이 늘고 갱신, 근거, 환각 문제가 남는다.
  2. retrieve-and-extract는 고칠 수 있는 색인을 쓰지만 문서 구간만 답할 수 있다.
  3. memory network는 과제마다 처음부터 학습한 벡터 기억을 썼다.
  4. RAG는 사전학습 retriever와 generator를 확률 모델 하나로 묶었다.
  5. 비교 문항은 지식이 어디에 있고 출력이 무엇인지부터 확인하라.
