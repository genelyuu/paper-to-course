Paper-to-Course

PDF 또는 arXiv 링크를 주면 자체 포함형 인터랙티브 HTML 튜토리얼을 만들어 줍니다. 단계별 수식 유도, 의사코드 한 줄씩 해설, 인터랙티브 실험, 퀴즈, 용어 툴팁과 연구 계보도를 담습니다. 브라우저로 열기만 하면 되며, 빌드 도구·서버·설정이 필요 없습니다.

WHY기존 논문 읽기가 실패하는 이유

기존 읽기의 어려움
  • 처음부터 읽다가 식 3에서 막히고, 결론으로 건너뜀
  • 초록의 대략적인 내용만 기억에 남음
  • 논문이 전제하는 선수 지식이 부족함
  • 형식이 먼저, 직관은 나중에 와서 인지 순서가 뒤집힘
Paper-to-Course의 순서 전환
  • 직관을 먼저 세우고, 형식화는 나중에
  • 배경을 먼저, 논문의 기여는 그다음에
  • 질문을 먼저, 답은 나중에
  • 모듈 0에서 용어집을 받은 뒤 본문으로 진입

PIPELINE5단계 파이프라인: PDF에서 인터랙티브 강의까지

1

심층 읽기

세 번 읽기: 구조 훑기 → 수식·결과·데이터셋 추출 → 서사 흐름 파악. 목표: 가르칠 수 있을 만큼 이해하기.

3회 독해
2

지식 확장

WebSearch로 선수 개념, 관련 연구, 연구 맥락을 보충. "호기심 많은 실무자"가 모르는 것은 무엇인가? 논문이 전제하는 배경지식은 무엇인가?

웹 검색 확장
3

강의 설계

5–8개 모듈을 배경 → 문제 → 연구 지형 → 핵심 통찰 → 방법 → 실험 → 시사점 순으로 구성. 모듈 0은 필수.

5–8개 모듈 · 서사 구조
3.5

모듈 브리프 (복잡한 논문)

모듈 7개 이상이면 먼저 브리프 작성: 교수 흐름, 사전 추출 수식, 인터랙티브 요소 체크리스트. 하위 에이전트에 나눠 맡기며, 한 번에 3개 모듈씩 처리.

병렬 하위 에이전트 배분
4

빌드

디렉터리를 만들고 CSS·JS·푸터·빌드 스크립트를 복사한 뒤 HTML 셸을 맞춤 설정하고, 표지와 각 모듈을 작성. cat 명령 한 줄로 index.html 조립.

cat → index.html
5

검토와 열기

15항목 체크리스트: 용어 툴팁, 수식 직관, 시각 밀도 50% 이상, 반응형 레이아웃, 한계 노출, 모듈 전환.

15항목 검토 체크리스트

FEATURES핵심 기능

무의존 실행

IIFE 구조, 프레임워크 없음. Google Fonts와 KaTeX CDN만 사용하며, 첫 로드 후 오프라인에서도 동작합니다.

한 줄 조립

cat _base _cover modules _footer > index, 번들러 불필요.

이중 언어 용어

기본 출력은 한국어이며 입력 언어를 자동 감지합니다. 한국어 설명(English Term) 형식.

5색 팔레트

Vermillion / Coral / Teal / Amber / Forest. _base.html에서 하나를 고르면 나머지는 자동 적용.

응용 능력 테스트

객관식은 "어떻게 예측할까?"와 "어디서 문제가 생겼을까?"를 우선 묻고, 오답에는 격려하는 해설을 붙입니다.

병렬 빌드

복잡한 논문(모듈 7개 이상)은 모듈 브리프와 하위 에이전트 배분으로 한 번에 3개 모듈씩 병렬 작성.

PHILOSOPHY교육 철학

1직관 우선, 각 수식을 일상 언어로 먼저 설명하고 수학을 제시
2논문의 이야기, 모듈은 요약이 아니라 한 장
3시각 50% 이상, 텍스트 블록은 2–3문장 이내, 목록은 카드로
4한 화면에 한 개념, 텍스트 벽 금지
5모든 것을 의심, 한계를 드러내고 가정에 도전
6지식 확장, 선수 개념 + 연구 계보 + 관련 연구
7입문 안내, 모듈 0에서 학습자에게 용어집을 먼저 제공
